# Редактор тем tvision-rs

Тема — это все 135 цветов палитры приложения: рабочий стол, меню и
строка состояния, три вида окон, три вида диалогов, окно справки. Редактор
меняет их с живым предпросмотром и сохраняет в отдельный файл `.tvtheme`,
который программа подключает одной строкой.

```text
cargo run -p tvtheme                        # новая тема
cargo run -p tvtheme -- themes/sea.tvtheme  # открыть (или создать) файл
```

## Работа

1. **Группа** и **Цвет** слева — что меняем (как в `ColorDialog`): например,
   «Серый диалог» → «Кнопка по умолчанию».
2. **Текст** и **Фон** — сетки 16 цветов: щелчок или стрелки. Меняется
   только та сторона, которую трогали.
3. **F5 / F6** — 256 цветов для текста / фона (окно с палитрой xterm).
4. **Предпросмотр** справа сразу показывает результат на образцах: меню
   с выбранным пунктом, синее и бирюзовое окна с текстом и выделением,
   диалог с подписями, полями, флажками, переключателями, списком и
   кнопками, строку состояния.
5. Под образцом — номер цвета в палитре, запись цвета (`lightcyan/blue`) и
   что было в основе.

| Клавиши | Что делают |
|---------|-----------|
| Tab | между списками и сетками |
| F5, F6 | 256 цветов для текста / фона |
| Ctrl+C, Ctrl+V | скопировать цвет пункта / вставить в другой пункт |
| «Правка → Сбросить к основе» | вернуть цвет пункта как в основе |
| Ctrl+Z, Ctrl+Y | отменить / повторить |
| F4 | свойства темы: имя, описание, основа |
| Ctrl+T | тема на весь редактор (проверить на живом интерфейсе) и обратно |
| «Вид → Настройки…» | цвета и язык самого редактора (см. ниже) |
| F2, F3 | сохранить / открыть `.tvtheme` |
| F9 | экспорт в Rust: константа с палитрой рядом с файлом темы |
| F7 | показать этот код |

**Основа** — встроенная палитра (классическая, gruvbox, чёрно-белая,
монохромная), с которой тема сравнивается: в файл попадают только
отличия. Новая тема создаётся от любой из них («Файл → Новая тема»).

## Настройки редактора

**Вид → Настройки…** — стандартный диалог `tvision::settings`
([урок 16](../../docs/guide/16-settings.md)): в каких цветах работает
**сам редактор** (тема из `themes/` рядом с программой или в текущем
каталоге, встроенные), цвета терминала, узор фона, язык надписей
библиотеки, мышь. Редактируемую тему это не меняет; Ctrl+T после этого
возвращает к цветам из настроек.

Настройки лежат в `tvtheme.settings.json` **рядом с программой**
(другой путь — `TVISION_SETTINGS`), применяются при запуске, а при выходе
запоминается, где стоит окно редактора. Если файла ещё нет, язык —
русский.

## Файл `.tvtheme`

```json
{
  "tvtheme": 1,
  "name": "Морская",
  "description": "Бирюзовые диалоги на синем рабочем столе (16 цветов)",
  "base": "classic",
  "colors": [
    {"index": 1, "item": "Рабочий стол: фон", "color": "lightcyan/blue"},
    {"index": 2, "item": "Меню и строка состояния: пункт", "color": "white/blue"},
    {"index": 42, "item": "Серый диалог: кнопка по умолчанию", "color": "221/24"}
  ]
}
```

* `index` — номер цвета в палитре приложения (1–135); `item` — только
  подсказка для человека, при чтении не нужен.
* `color` — `текст/фон`. Каждая сторона: имя цвета BIOS (`black`, `blue`,
  `green`, `cyan`, `red`, `magenta`, `brown`, `lightgray`, `darkgray`,
  `lightblue`, `lightgreen`, `lightcyan`, `lightred`, `lightmagenta`,
  `yellow`, `white`), номер xterm-256 (`221`) или `#rrggbb` (берётся
  ближайший из 256).
* Цвета BIOS видны в любом терминале; 256 цветов — в современных, а в
  16-цветных заменяются ближайшими.

Файл можно править и руками — редактор и программа читают его одинаково.

## Подключение в программе

```rust
app.load_theme("themes/sea.tvtheme")?;               // из файла
```

Или без единой строки кода — переменной окружения:

```text
TVISION_THEME=themes/sea.tvtheme ./моя_программа
```

Список тем и выбор с предпросмотром:

```rust
let (found, _errors) = tvision::theme::find_themes("themes");
let themes: Vec<_> = found.into_iter().map(|(_, t)| t).collect();
if let Some(i) = tvision::theme::choose_theme(app, &themes) {
    // themes[i] уже подключена — можно запомнить выбор
}
```

Встроить тему без файла — F9 в редакторе даёт константу:

```rust
pub const SEA_THEME: &[tvision::color::Attr] = &[ /* 135 цветов */ ];
app.palette = SEA_THEME.to_vec();
```

Пример программы с меню тем — `cargo run --example themes`; образцы тем
— в каталоге `themes/` репозитория: «Классическая», «Gruvbox»,
«Морская», «Матрица», «Полночь».

## Как устроено

* `tvision::theme` (в библиотеке) — тема, файл, группы цветов,
  `choose_theme`, `find_themes`; `Program::set_theme`, `load_theme`.
* `preview` — предпросмотр: настоящие виджеты, нарисованные через
  `DrawCtx::sub_themed` в цветах темы, — цвета самого редактора не
  меняются.
* `editor` — окно редактора, команды, файлы, отмена.

```text
cargo test -p tvtheme
```
