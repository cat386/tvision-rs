# Документация tvision-rs

**tvision-rs** — библиотека текстового интерфейса Turbo Vision, перенесённая
с C++ ([magiblot/tvision](https://github.com/magiblot/tvision)) на Rust.
С ней в терминале строятся программы с окнами, меню, диалогами, мышью и
справкой — как в Borland Turbo Pascal / Turbo C++, но в современных
терминалах Linux, macOS и Windows.

В Rust-коде крейт называется `tvision` (`use tvision::*;`), в `Cargo.toml` —
`tvision-rs`.

## С чего начать

Если вы раньше не работали с Turbo Vision, читайте по порядку первые
четыре главы. Если вы знаете оригинал на C++ или Pascal, начните с главы
«Перенос программ» — в ней собраны все отличия.

## Соглашения в тексте

* **Представление** (view) — любой видимый объект интерфейса: кнопка,
  строка ввода, окно, рабочий стол. В C++ это наследник `TView`, здесь —
  тип, реализующий трейт [`View`](04-views.md).
* **Группа** — представление, которое владеет другими (окно, диалог,
  рабочий стол). Её дети называются **подпредставлениями**.
* **C-строка** — строка с горячей буквой между тильдами: `"~F~ile"`,
  `"O~K~"`. Буква между `~` выделяется цветом и срабатывает по Alt+буква.
* Координаты всегда целые и считаются в **ячейках** экрана; ось Y идёт
  вниз. Прямоугольник `Rect::new(ax, ay, bx, by)` включает левый верхний
  угол `(ax, ay)` и **не включает** правый нижний `(bx, by)` — как
  `TRect` в оригинале.
* В примерах кода опущено `use tvision::*;`, если оно очевидно.

## Где ещё смотреть

* Комментарии в исходниках (на русском) — у каждого публичного типа и метода.
  `cargo doc --open` соберёт их в HTML.
* Примеры в каталоге `examples/` (см. [главу 1](01-start.md#примеры-из-комплекта)).
* Тесты в `tests/` — короткие рабочие сценарии для каждого элемента.
