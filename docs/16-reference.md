# 16. Справочник констант

Все модули доступны после `use tvision::*;` (`cm::OK`, `bf::DEFAULT`…).

## `cm` — команды

Номера совпадают с оригиналом. Команды 0–255 можно запрещать
(`disable_command`), команды больше 255 — нет. Свои команды нумеруйте
от 100 до 255 или от 1000 и выше (кроме занятых ниже).

### Общие и окон

В скобках — клавиши, которые обычно назначают этим командам в строке
состояния или меню (сами по себе они к командам не привязаны).

| Константа | № | Смысл |
|-----------|---|-------|
| `VALID` | 0 | проверка «готово к работе» (`valid(cm::VALID)` при вставке окна) |
| `QUIT` | 1 | выход из программы |
| `ERROR` | 2 | ошибка |
| `MENU` | 3 | открыть меню (обычно F10) |
| `CLOSE` | 4 | закрыть окно (Alt+F3) |
| `ZOOM` | 5 | распахнуть / восстановить (F5) |
| `RESIZE` | 6 | двигать / менять размер с клавиатуры (Ctrl+F5) |
| `NEXT` | 7 | следующее окно (F6) |
| `PREV` | 8 | предыдущее окно (Shift+F6) |
| `HELP` | 9 | справка (F1) |

### Диалоги

| Константа | № | Смысл |
|-----------|---|-------|
| `OK` | 10 | OK — завершает модальный диалог |
| `CANCEL` | 11 | Отмена — завершает модальный диалог (Esc) |
| `YES` | 12 | Да — завершает модальный диалог |
| `NO` | 13 | Нет — завершает модальный диалог |
| `DEFAULT` | 14 | сообщение: нажать кнопку по умолчанию (Enter) |

### Приложение

| Константа | № | | Константа | № |
|-----------|---|-|-----------|---|
| `CUT` | 20 | | `NEW` | 30 |
| `COPY` | 21 | | `OPEN` | 31 |
| `PASTE` | 22 | | `SAVE` | 32 |
| `UNDO` | 23 | | `SAVE_AS` | 33 |
| `CLEAR` | 24 | | `SAVE_ALL` | 34 |
| `TILE` | 25 | | `CH_DIR` | 35 |
| `CASCADE` | 26 | | `DOS_SHELL` | 36 |
| `REDO` | 27 | | `CLOSE_ALL` | 37 |

`TILE` и `CASCADE` обрабатывает рабочий стол; `CUT`…`REDO`, `SAVE`,
`SAVE_AS` — редактор в фокусе; остальные — ваша программа.

## `kb` — клавиши

Конструкторы: `key(Key)`, `alt(char)`, `ctrl(char)`, `f(n)`, `alt_f(n)`,
`ctrl_f(n)`, `shift_f(n)`.

Константы: `ENTER`, `ESC`, `TAB`, `SHIFT_TAB`, `F1`, `F2`, `F3`, `F5`,
`F6`, `F10`, `ALT_X`, `ALT_F3`, `CTRL_F5`, `SHIFT_F6`.

Кнопки мыши (`event::`): `MB_LEFT` = 1, `MB_RIGHT` = 2, `MB_MIDDLE` = 4.

| Константа | Значение | Смысл |
|-----------|----------|-------|

| Константа | Значение | Смысл |
|-----------|----------|-------|
| `SELECTABLE` | `0x001` | может получать фокус |

| `FRAMED` | `0x008` | есть рамка |

## `gf` — изменение размера (`ViewState::grow_mode`)

| Константа | Значение | Смысл |
|-----------|----------|-------|
| `GROW_LO_X` | `0x01` | левая граница следует за правым краем владельца |
| `GROW_LO_Y` | `0x02` | верхняя — за нижним |
| `GROW_HI_X` | `0x04` | правая — за правым |
| `GROW_HI_Y` | `0x08` | нижняя — за нижним |
| `GROW_ALL` | `0x0F` | все четыре |
| `GROW_REL` | `0x10` | пропорционально |
| `FIXED` | `0x20` | размер не ограничен владельцем |

## `dm` — перетаскивание (`ViewState::drag_mode`)

`DRAG_MOVE` (`0x01`), `DRAG_GROW` (`0x02`), `DRAG_GROW_LEFT` (`0x04`),
`LIMIT_LO_X` (`0x10`), `LIMIT_LO_Y` (`0x20`), `LIMIT_HI_X` (`0x40`),
`LIMIT_HI_Y` (`0x80`), `LIMIT_ALL` (`0xF0`). По умолчанию — `LIMIT_LO_Y`
(окно не уходит выше верхнего края рабочего стола).

## `wf` — флаги окна (`Window::flags`)

| Константа | Значение | Смысл |
|-----------|----------|-------|
| `MOVE` | `0x01` | можно двигать |
| `GROW` | `0x02` | можно менять размер |
| `CLOSE` | `0x04` | кнопка закрытия `[■]` |
| `ZOOM` | `0x08` | кнопка распахивания `[↑]` |

`window::MIN_WIN_SIZE` — минимальный размер окна (16×6).

## `bf` — флаги кнопки

`NORMAL` (`0x00`), `DEFAULT` (`0x01`), `LEFT_JUST` (`0x02`),
`BROADCAST` (`0x04`), `GRAB_FOCUS` (`0x08`).

## Контексты справки

`view::HC_NO_CONTEXT` = 0 (нет контекста), `view::HC_DRAGGING` = 1
(окно перетаскивают). Свои контексты — с 2 (так нумерует и `tvhc`).
