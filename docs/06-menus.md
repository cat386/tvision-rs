# 6. Меню и строка состояния

## Меню

Меню описывается деревом `Menu` (аналог `TMenu`/`TMenuItem`/`TSubMenu`) и
строится цепочкой вызовов:

```rust
use tvision::*;

const CM_FIND: u16 = 110;
const CM_ABOUT: u16 = 111;

fn main_menu() -> Menu {
    Menu::new()
        .submenu(
            "~Ф~айл",
            Menu::new()
                .item_key("~О~ткрыть...", cm::OPEN, kb::F3, "F3")
                .item_key("~С~охранить", cm::SAVE, kb::F2, "F2")
                .item("Сохранить ~к~ак...", cm::SAVE_AS)
                .separator()
                .item_key("~В~ыход", cm::QUIT, kb::ALT_X, "Alt-X"),
        )
        .submenu(
            "~П~равка",
            Menu::new()
                .item_key("~Н~айти...", CM_FIND, kb::ctrl('F'), "Ctrl-F")
                .help(40) // контекст справки последнего пункта
                .submenu("~Е~щё", Menu::new().item("~О~ программе", CM_ABOUT)),
        )
}
```

| Метод | Что добавляет |
|-------|---------------|
| `item(name, command)` | пункт-команду |
| `item_key(name, command, key, param)` | пункт с клавишей быстрого вызова `key`; `param` — её подпись справа (`"F3"`, `"Ctrl-F"`) |
| `submenu(name, menu)` | подменю (в строке меню — пункт верхнего уровня) |
| `submenu_key(name, key, menu)` | подменю, которое открывается ещё и клавишей (как «≡» по Alt+Пробел в `tvdemo`) |
| `separator()` | разделитель |
| `help(ctx)` | контекст справки последнего пункта — строка состояния и F1 показывают его, пока пункт подсвечен |

`name` — C-строка: буква между `~` выделяется и выбирает пункт.

### Как работает меню

* F10 (команда `cm::MENU`, обычно через невидимый пункт строки
  состояния) или щелчок по строке меню открывает меню.
* Alt+буква открывает подменю верхнего уровня с этой горячей буквой.
* В открытом меню: стрелки, Enter — выбрать, Esc — закрыть уровень,
  буква — пункт с этой горячей буквой, мышь — как обычно.
* **Клавиши быстрого вызова** (`item_key`) работают и при закрытом меню:
  строка меню ловит их в фазе `PreProcess` (раньше элемента в фокусе) и
  превращает в команды. Поэтому не назначайте пунктам меню клавиши, которые
  нужны строкам ввода и редактору (буквы, Ctrl+стрелки).
* Запрещённые команды рисуются серым и не выбираются
  ([глава 3](03-events.md#запрет-команд)).
* Выбранный пункт посылает свою команду обычным путём — она дойдёт до
  активного окна и затем до `AppHandler`.

Горячие буквы меню работают в любой раскладке: Alt+A открывает «~Ф~айл»
так же, как Alt+Ф ([глава 13](13-locale.md)).

Пока меню открыто, программа ведёт **сеанс меню** (`MenuSession`): он
перехватывает все события и рисует выпадающие окна поверх экрана. Сам
вызывать его не нужно.

## Контекстное (всплывающее) меню

```rust
use std::rc::Rc;
use tvision::*;

const CM_COPY_PATH: u16 = 130;

struct App;

impl AppHandler for App {
    fn handle_event(&mut self, app: &mut Program, ev: &mut Event) {
        // Правая кнопка мыши по свободному месту рабочего стола.
        if let Event::MouseDown(m) = ev {
            if m.buttons & event::MB_RIGHT != 0 {
                let menu = Rc::new(Menu::new().item("~К~опировать путь", CM_COPY_PATH).separator().item("~М~озаика", cm::TILE));
                app.ctx.popup_menu(menu, m.pos); // позиция — абсолютная
                ev.clear();
            }
        }
    }
}
```

Из представления — `ctx.popup_menu(menu, pos)`; переведите локальную точку
в абсолютную через `dc.origin()` при отрисовке или храните абсолютные
координаты щелчка (для обработчика приложения координаты события мыши уже
абсолютные).

## Строка состояния

Строка состояния (`TStatusLine`) показывает подсказки клавиш и превращает
нажатия этих клавиш в команды. Её содержимое зависит от **контекста
справки** представления в фокусе: каждый набор `StatusDef` действует для
диапазона контекстов `min..=max`, используется первый подходящий.

```rust
use tvision::*;

const HC_EDITOR: u16 = 100;
const CM_COMPILE: u16 = 140;

fn status() -> Vec<StatusDef> {
    vec![
        // В окнах редактора (help_ctx == HC_EDITOR):
        StatusDef::range(HC_EDITOR, HC_EDITOR, vec![
            StatusItem::new("~F2~ Сохранить", kb::F2, cm::SAVE),
            StatusItem::new("~F9~ Собрать", kb::f(9), CM_COMPILE),
            StatusItem::new("", kb::F10, cm::MENU),
        ]),
        // Во всех остальных случаях:
        StatusDef::all(vec![
            StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT),
            StatusItem::new("~F3~ Открыть", kb::F3, cm::OPEN),
            StatusItem::new("", kb::F10, cm::MENU),     // невидимые пункты:
            StatusItem::new("", kb::ALT_F3, cm::CLOSE), // только клавиши
            StatusItem::new("", kb::F5, cm::ZOOM),
            StatusItem::new("", kb::F6, cm::NEXT),
            StatusItem::new("", kb::CTRL_F5, cm::RESIZE),
        ]),
    ]
}
```

* Текст пункта — C-строка: часть между `~` выделяется (обычно сама
  клавиша).
* Пункт с пустым текстом не виден, но его клавиша работает — так задают
  F10, Alt+F3, F5, F6, Ctrl+F5.
* Пункты с запрещённой командой рисуются серым и не срабатывают.
* Пункт с командой 0 — просто надпись (щелчок ничего не делает).
* Строка состояния видит клавиши и **во время модального диалога**: её
  пункты работают и там (например, F1 — справка).

Контекст справки задаётся полем `vs.help_ctx` у окна, диалога или
элемента; берётся у самого глубокого представления в фокусе, у которого он
не 0. Пока открыто меню — контекст подсвеченного пункта (`Menu::help`).

### Подсказка справа

```rust
use tvision::*;

fn add_hint(app: &mut Program) {
    if let Some(sl) = app.status_line_mut() {
        sl.hint = Some(Box::new(|ctx| match ctx {
            100 => "Редактирование текста".to_string(),
            _ => String::new(),
        }));
    }
}
```

`hint` получает текущий контекст справки и возвращает текст, который
рисуется справа от пунктов (аналог `TStatusLine::hint`).
