# Урок 1. Первая программа

В этом уроке вы создадите проект, подключите библиотеку и запустите
программу, которая занимает весь терминал и закрывается по Alt+X. Это
займёт минут десять.

## Что такое текстовый интерфейс

Обычные консольные программы печатают строки одну за другой: вывод
«уезжает» вверх, как лента. Программа с **текстовым интерфейсом** ведёт
себя иначе: она занимает **весь экран терминала** и рисует на нём окна,
меню и кнопки — из символов. Мышь и клавиатура при этом работают, как в
обычной графической программе: можно щёлкать, таскать окна, выбирать
пункты меню.

Так выглядели программы для DOS: Norton Commander, Turbo Pascal, Far.
Многие из них были написаны на библиотеке **Turbo Vision** фирмы Borland.
`tvision-rs` — её перевод на Rust.

```text
  Файл  Правка  Окна                                    ← строка меню
░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░    ← рабочий стол (фон)
░░░░╔═[■]══════ Заметки ═══════1═[↑]═╗░░░░░░░░░░░░░░
░░░░║Купить хлеб                     ║░░░░░░░░░░░░░░    ← окно
░░░░║Позвонить маме                  ║░░░░░░░░░░░░░░
░░░░╚════════════════════════════════╝░░░░░░░░░░░░░░
 Alt-X Выход  F2 Сохранить  F3 Открыть                  ← строка состояния
```

## Что нужно

* Rust (`cargo` и `rustc`) не очень старой версии — 1.70 или новее.
  Проверить: `cargo --version`; обновить: `rustup update`.
* Любой терминал: на Linux и macOS — стандартный, на Windows — Windows
  Terminal или обычная консоль Windows 10 и новее.

Других библиотек и программ не нужно — `tvision-rs` ни от чего не
зависит.

## Шаг 1. Создайте проект

```text
cargo new hello-tv
cd hello-tv
```

Откройте файл `Cargo.toml` и допишите в раздел `[dependencies]` строку:

```toml
[dependencies]
tvision-rs = { git = "https://github.com/cat386/tvision-rs" }
```

> Пакет называется `tvision-rs`, а в коде библиотека называется короче —
> `tvision`. Поэтому ниже `use tvision::*`.

## Шаг 2. Напишите программу

Замените содержимое `src/main.rs` этим кодом:

```rust,ignore
//! Урок 1. Самая простая программа: пустой рабочий стол и строка состояния.
//!
//! Запуск: `cargo run --example learn_01_hello`. Выход — Alt+X или щелчок
//! по надписи «Alt-X Выход» внизу экрана.

// Подключаем всё нужное из библиотеки одной строкой.
use tvision::*;

fn main() -> std::io::Result<()> {
    // Строка состояния — нижняя строка экрана. В ней один пункт:
    // надпись «Alt-X Выход», клавиша Alt+X и команда «выйти из программы».
    let status = vec![StatusDef::all(vec![StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT)])];

    // Создаём программу: она займёт весь терминал.
    // Первый аргумент — меню (его пока нет), второй — строка состояния.
    let mut app = Program::with_terminal(None, Some(status))?;

    // Запускаем. `run` возвращается, когда пользователь выходит из программы;
    // терминал при этом возвращается в обычный вид.
    app.run(&mut program::NoHandler);
    Ok(())
}
```

## Шаг 3. Запустите

```text
cargo run
```

Первая сборка займёт немного времени. Потом терминал очистится и
покажет серо-полосатый **рабочий стол** и внизу — **строку состояния** с
надписью «Alt-X Выход». Нажмите Alt+X (или щёлкните по надписи мышью) —
программа закроется, и терминал вернётся в обычный вид.

> Тот же пример есть в репозитории библиотеки:
> `cargo run --example learn_01_hello`.

## Что здесь происходит

Разберём программу по строчкам.

**`use tvision::*;`** — подключает всё из библиотеки: типы, функции,
константы. Дальше в уроках эта строка будет всегда.

**Строка состояния.**

```rust,ignore
let status = vec![StatusDef::all(vec![StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT)])];
```

Читается изнутри наружу:

* `StatusItem::new(надпись, клавиша, команда)` — один пункт строки
  состояния. Надпись `"~Alt-X~ Выход"`: часть между тильдами `~` будет
  выделена цветом. Клавиша `kb::ALT_X` — Alt+X. Команда `cm::QUIT` —
  «выйти из программы».
* `StatusDef::all(пункты)` — набор пунктов, который показывается всегда.
  (Можно сделать несколько наборов для разных случаев — это потом.)
* `vec![…]` — список наборов. У нас один.

**Программа.**

```rust,ignore
let mut app = Program::with_terminal(None, Some(status))?;
```

`Program` — это вся программа целиком: экран, рабочий стол, меню, строка
состояния. `with_terminal` переводит терминал в полноэкранный режим.
Первый аргумент — меню: его пока нет, поэтому `None`. Второй — строка
состояния. Знак `?` в конце передаёт ошибку наружу, если терминал не
удалось подготовить (например, программу запустили без терминала).

**Запуск.**

```rust,ignore
app.run(&mut program::NoHandler);
```

`run` запускает **цикл событий** — сердце любой программы с
интерфейсом. Программа ждёт, пока пользователь что-нибудь сделает
(нажмёт клавишу, щёлкнет мышью), обрабатывает это и перерисовывает
экран — и так снова и снова, пока не придёт команда выхода. Тогда `run`
возвращается.

`program::NoHandler` — «ничего не делающий» обработчик. В следующем уроке
мы напишем свой и научим программу реагировать на команды.

## Словарик

Эти слова будут встречаться во всех уроках.

| Слово | Что значит |
|-------|-----------|
| **представление** (view) | всё, что видно на экране: окно, кнопка, строка меню, рабочий стол |
| **событие** (event) | что-то произошло: нажата клавиша, щёлкнула мышь, выбрана команда |
| **команда** (command) | число, означающее действие: «выйти», «открыть файл», «OK». Пункты меню и кнопки посылают команды |
| **рабочий стол** (desktop) | область между строкой меню и строкой состояния, на которой лежат окна |
| **строка состояния** (status line) | нижняя строка с подсказками клавиш |
| **модальное окно** | окно, которое нужно закрыть, прежде чем вернуться к остальной программе (диалог «Сохранить?») |

## Попробуйте

1. Добавьте второй пункт в строку состояния:
   `StatusItem::new("~F10~ Меню", kb::F10, cm::MENU)`. Пока меню нет,
   он ничего не делает — но надпись появится.
2. Поменяйте надпись на `"Выход ~Alt+X~"` и посмотрите, какая часть
   выделяется.

## Если что-то не так

* **Программа сразу завершается с ошибкой «стандартный ввод не является
  терминалом»** — её
  запустили не в терминале (например, из окна вывода редактора кода).
  Запустите `cargo run` в настоящем терминале.
* **После аварийного завершения терминал «сломался»** (не видно
  набираемых символов) — наберите вслепую `reset` и Enter.
* **Русские буквы — «кракозябры»** — в терминале не UTF-8. В Linux и
  macOS это почти не встречается; в старой консоли Windows выполните
  `chcp 65001`.
