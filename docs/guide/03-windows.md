# Урок 3. Окна

Окно — главный строительный блок интерфейса. В этом уроке программа по
F3 открывает новые окна с текстом; их можно двигать мышью, растягивать,
распахивать на весь экран и закрывать.

## Программа

Файл `examples/learn_03_windows.rs`:

```rust,ignore
//! Урок 3. Окна: создать, передвинуть, распахнуть, закрыть.
//!
//! Запуск: `cargo run --example learn_03_windows`. F3 — новое окно,
//! F6 — следующее окно, F5 — распахнуть, Alt+F3 — закрыть, Alt+X — выход.
//! Окна можно таскать мышью за заголовок и тянуть за правый нижний угол.

use tvision::*;

const CM_NEW_WINDOW: u16 = 100;

struct App {
    /// Сколько окон уже открыто за всё время — для заголовков и номеров.
    opened: i32,
}

impl App {
    fn new_window(&mut self, app: &mut Program) {
        self.opened += 1;
        let n = self.opened;

        // Каждое следующее окно — чуть правее и ниже предыдущего.
        let shift = (n - 1) % 8;
        let bounds = Rect::new(2 + shift * 3, 1 + shift, 2 + shift * 3 + 40, 1 + shift + 10);

        // Номер 1–9 виден в рамке; Alt+номер выбирает окно. 0 — без номера.
        let number = if n < 10 { n as i16 } else { 0 };
        let mut w = Window::new(bounds, &format!("Окно {}", n), number);

        // Внутрь окна кладём текст. `interior()` — место внутри рамки.
        let text =
            StaticText::new(w.interior(), "Тащите окно мышью за заголовок, тяните за правый нижний угол.\n\nF5 — распахнуть, Alt+F3 — закрыть.");
        w.add(text);

        // Окно — на рабочий стол.
        app.insert_window(w);
    }
}

impl AppHandler for App {
    fn handle_event(&mut self, app: &mut Program, ev: &mut Event) {
        if ev.command() == Some(CM_NEW_WINDOW) {
            self.new_window(app);
            ev.clear();
        }
    }
}

fn menu() -> Menu {
    Menu::new()
        .submenu(
            "~Ф~айл",
            Menu::new().item_key("~Н~овое окно", CM_NEW_WINDOW, kb::F3, "F3").separator().item_key("~В~ыход", cm::QUIT, kb::ALT_X, "Alt-X"),
        )
        // Команды окон — стандартные: их обрабатывают сами окна и рабочий стол.
        .submenu(
            "~О~кна",
            Menu::new()
                .item("~М~озаика", cm::TILE)
                .item("~К~аскад", cm::CASCADE)
                .separator()
                .item_key("~С~ледующее", cm::NEXT, kb::F6, "F6")
                .item_key("~Р~аспахнуть", cm::ZOOM, kb::F5, "F5")
                .item_key("~З~акрыть", cm::CLOSE, kb::ALT_F3, "Alt-F3"),
        )
}

fn status() -> Vec<StatusDef> {
    vec![StatusDef::all(vec![
        StatusItem::new("~F3~ Новое", kb::F3, CM_NEW_WINDOW),
        StatusItem::new("~F6~ Следующее", kb::F6, cm::NEXT),
        StatusItem::new("~F5~ Распахнуть", kb::F5, cm::ZOOM),
        StatusItem::new("~Alt-F3~ Закрыть", kb::ALT_F3, cm::CLOSE),
        StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT),
        StatusItem::new("", kb::F10, cm::MENU),
    ])]
}

fn main() -> std::io::Result<()> {
    let mut app = Program::with_terminal(Some(menu()), Some(status()))?;
    let mut h = App { opened: 0 };
    h.new_window(&mut app); // одно окно сразу при запуске
    app.run(&mut h);
    Ok(())
}
```

Запуск: `cargo run --example learn_03_windows`. Нажмите F3 несколько раз,
потом попробуйте:

* перетащить окно мышью за верхнюю рамку;
* потянуть за правый нижний угол — окно станет больше;
* щёлкнуть по значку `[↑]` справа вверху или нажать F5 — окно
  распахнётся на весь рабочий стол;
* щёлкнуть по `[■]` слева вверху или нажать Alt+F3 — окно закроется;
* F6 — перейти к следующему окну, Alt+1, Alt+2… — к окну с этим номером;
* меню «Окна» → «Мозаика» — разложить окна плиткой.

Всё это умеют сами окна — нам не пришлось писать для этого ни строчки.

## Разбор

### Создание окна

```rust,ignore
let mut w = Window::new(bounds, &format!("Окно {}", n), number);
```

`Window::new` принимает три вещи:

* **границы** `bounds` — прямоугольник, который окно займёт на рабочем
  столе;
* **заголовок** — текст в верхней рамке;
* **номер** — цифра 1–9 в рамке справа; по Alt+цифра окно выбирается.
  Номер 0 — без номера.

### Прямоугольник

```rust,ignore
let bounds = Rect::new(2 + shift * 3, 1 + shift, 2 + shift * 3 + 40, 1 + shift + 10);
```

`Rect::new(x1, y1, x2, y2)` — прямоугольник от левого верхнего угла
`(x1, y1)` до правого нижнего `(x2, y2)`. Единица — одна клетка
терминала: `x` — столбец, `y` — строка, счёт с нуля, `y` растёт вниз.
Окно выше — шириной `40` и высотой `10` клеток.

> Правый нижний угол **не входит** в прямоугольник: ширина `Rect::new(2,
> 1, 42, 11)` — ровно `42 - 2 = 40`. Подробно — в [уроке 4](04-coordinates.md).

### Что положить в окно

```rust,ignore
let text = StaticText::new(w.interior(), "…");
w.add(text);
```

* `StaticText` — просто текст. Длинные строки сами переносятся по
  словам, `\n` — новая строка.
* `w.interior()` — прямоугольник **внутри рамки**. Текст займёт всё окно,
  кроме рамки.
* `w.add(…)` кладёт представление в окно. Окно становится его
  **владельцем**: дальше оно само рисует, двигает и удаляет своих
  «детей».

### Окно — на рабочий стол

```rust,ignore
app.insert_window(w);
```

Окно отдаётся программе: оно появляется поверх остальных и получает
фокус (его рамка становится двойной — так видно активное окно).

### Стандартные команды окон

```rust,ignore
.item("~М~озаика", cm::TILE)
.item_key("~С~ледующее", cm::NEXT, kb::F6, "F6")
.item_key("~Р~аспахнуть", cm::ZOOM, kb::F5, "F5")
.item_key("~З~акрыть", cm::CLOSE, kb::ALT_F3, "Alt-F3")
```

Это команды библиотеки, их не нужно обрабатывать самим: `cm::ZOOM` и
`cm::CLOSE` обрабатывает активное окно, `cm::NEXT`, `cm::TILE` и
`cm::CASCADE` — рабочий стол. Достаточно поставить их в меню или в
строку состояния.

### Окно при запуске

```rust,ignore
let mut h = App { opened: 0 };
h.new_window(&mut app);
app.run(&mut h);
```

До `run` можно подготовить экран: открыть окна, задать узор фона и так
далее. Здесь мы вызываем свой же метод `new_window`.

## Попробуйте

1. Поменяйте узор рабочего стола: до `run` добавьте
   `app.desktop_mut().set_pattern('▒');`.
2. Сделайте окно, которое нельзя закрыть: `w.flags &= !wf::CLOSE;` —
   значок `[■]` исчезнет, Alt+F3 перестанет работать.
3. Откройте окно сразу во весь рабочий стол:
   `let r = app.desktop().group.vs.extent();` и `Window::new(r, …)`.

## Важно запомнить

* Окно = рамка + заголовок + номер + содержимое. Содержимое добавляется
  методом `add`.
* Место внутри рамки — `interior()`.
* Двигать, растягивать, распахивать и закрывать окна библиотека умеет
  сама; команды `cm::ZOOM`, `cm::CLOSE`, `cm::NEXT`, `cm::TILE` нужно
  только поставить в меню.
