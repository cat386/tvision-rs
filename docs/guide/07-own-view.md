# Урок 7. Своё представление

Готовых элементов много, но рано или поздно понадобится свой: график,
игровое поле, часы, особый индикатор. Сделаем простой — **счётчик**:
показывает число, пробел прибавляет 1.

## Программа

Файл `examples/learn_07_view.rs`:

```rust,ignore
//! Урок 7. Своё представление: счётчик.
//!
//! Запуск: `cargo run --example learn_07_view`. Пробел, Enter или щелчок —
//! прибавить 1; `-` — убавить; `0` — обнулить; Tab — к другому счётчику.
//! Alt+X — выход.

use tvision::*;

/// Счётчик. Любое представление — это структура с полем `vs`
/// (положение, размер, состояние) и своими данными.
pub struct Counter {
    pub vs: ViewState,
    pub value: i32,
}

impl Counter {
    pub fn new(x: i32, y: i32) -> Self {
        // Размер 20×1: одна строка шириной 20 клеток.
        let mut vs = ViewState::new(Rect::new(x, y, x + 20, y + 1));
        // SELECTABLE — может получать фокус (клавиатуру);
        // FIRST_CLICK — первый же щелчок мышью засчитывается.
        vs.options |= of::SELECTABLE | of::FIRST_CLICK;
        Counter { vs, value: 0 }
    }
}

impl View for Counter {
    // Пять служебных методов, одинаковых у всех представлений, пишет макрос.
    tvision::impl_view_basics!();

    /// Нарисовать себя. Вызывается при каждой перерисовке экрана.
    fn draw(&self, dc: &mut DrawCtx) {
        // Цвет берём по номеру из палитры (см. `palette` ниже):
        // 1 — обычный, 2 — когда счётчик в фокусе.
        let color = dc.color(if self.vs.is_focused() { 2 } else { 1 });
        // Сначала закрашиваем всю свою строку, потом пишем текст.
        dc.fill(self.vs.extent(), ' ', color);
        dc.write_str(1, 0, &format!("Счёт: {}", self.value), color);
    }

    /// Палитра: возьмём ту же, что у строки ввода, — так счётчик будет
    /// выглядеть «как поле» в любом диалоге.
    fn palette(&self) -> &'static [u8] {
        color::palettes::INPUT_LINE
    }

    /// Обработать событие: клавишу или мышь.
    fn handle_event(&mut self, ev: &mut Event, ctx: &mut Ctx) {
        // Стандартное поведение: щелчок по счётчику переводит на него фокус.
        view::default_handle_event(&self.vs, ev, ctx);
        match ev {
            Event::MouseDown(_) => {
                self.value += 1;
                ev.clear(); // событие обработано
            }
            // Клавиши получает только тот, кто в фокусе.
            Event::KeyDown(k) if self.vs.is_focused() => {
                match k.key {
                    Key::Char(' ') | Key::Enter => self.value += 1,
                    Key::Char('-') => self.value -= 1,
                    Key::Char('0') => self.value = 0,
                    _ => return, // чужая клавиша (например, Tab) — пусть обработают другие
                }
                ev.clear();
            }
            _ => {}
        }
    }
}

fn open_window(app: &mut Program) {
    let mut w = Window::new(Rect::new(10, 3, 46, 11), "Счётчики", 1);
    w.add(StaticText::new(Rect::new(2, 1, 34, 2), "Пробел +1, «-» −1, Tab — дальше"));
    w.add(Counter::new(2, 3));
    w.add(Counter::new(2, 5));
    app.insert_window(w);
}

fn main() -> std::io::Result<()> {
    let status = vec![StatusDef::all(vec![StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT)])];
    let mut app = Program::with_terminal(None, Some(status))?;
    open_window(&mut app);
    app.run(&mut program::NoHandler);
    Ok(())
}
```

Запуск: `cargo run --example learn_07_view`. В окне два счётчика. Пробел
или Enter прибавляет единицу, `-` вычитает, `0` обнуляет. Tab переводит
фокус на другой счётчик — он подсвечивается. Щелчок мышью тоже
прибавляет.

## Из чего состоит представление

Любое представление — это:

1. **структура** с полем `vs: ViewState` и своими данными;
2. **реализация трейта `View`**: как себя рисовать (`draw`) и как
   отвечать на события (`handle_event`).

### Структура

```rust,ignore
pub struct Counter {
    pub vs: ViewState,
    pub value: i32,
}
```

`ViewState` — общие для всех представлений сведения: где оно лежит
(`origin`), какого размера (`size`), в фокусе ли (`is_focused()`), какие
у него флаги. Создаётся из прямоугольника: `ViewState::new(rect)`.

### Флаги

```rust,ignore
vs.options |= of::SELECTABLE | of::FIRST_CLICK;
```

* `of::SELECTABLE` — представление может получить **фокус**, то есть
  клавиатуру. Без этого флага Tab его пропускает (так ведут себя подписи
  и тексты).
* `of::FIRST_CLICK` — первый же щелчок мышью засчитывается. Без него
  первый щелчок только переводит фокус.

### Служебные методы

```rust,ignore
impl View for Counter {
    tvision::impl_view_basics!();
```

Трейту `View` нужны пять одинаковых у всех служебных методов (доступ к
`vs` и приведение типов). Макрос `impl_view_basics!` пишет их за вас.
Он работает, если поле называется именно `vs`.

### Рисование

```rust,ignore
fn draw(&self, dc: &mut DrawCtx) {
    let color = dc.color(if self.vs.is_focused() { 2 } else { 1 });
    dc.fill(self.vs.extent(), ' ', color);
    dc.write_str(1, 0, &format!("Счёт: {}", self.value), color);
}
```

`draw` вызывается при каждой перерисовке экрана — после любого события.
Вам не нужно следить, изменилось ли что-то: просто рисуйте текущее
состояние.

* `dc` — «холст» представления. Координаты на нём **свои**: `(0, 0)` —
  левый верхний угол счётчика, где бы он ни лежал на экране.
* `dc.fill(прямоугольник, символ, цвет)` — залить. `self.vs.extent()` —
  весь свой прямоугольник. **Закрашивайте всю свою область**: что не
  нарисовано, останется от прошлого кадра.
* `dc.write_str(x, y, текст, цвет)` — написать строку.
* `dc.color(n)` — цвет номер `n` из **палитры** представления.

### Палитра — откуда берутся цвета

```rust,ignore
fn palette(&self) -> &'static [u8] {
    color::palettes::INPUT_LINE
}
```

Цвета в Turbo Vision задаются не напрямую, а **номерами**. Счётчик
говорит «мне цвет номер 1», палитра строки ввода переводит его в номер
цвета диалога, палитра диалога — в номер цвета программы, а там уже
настоящий цвет. Зачем так сложно? Чтобы один и тот же элемент выглядел
правильно и в сером диалоге, и в синем окне, а пользователь мог
перекрасить всю программу в одном месте.

На практике: возьмите палитру готового элемента, который похож на ваш
(`INPUT_LINE`, `STATIC_TEXT`, `BUTTON`, `LIST_VIEWER`), и используйте
номера 1, 2… как у него. Для `INPUT_LINE` 1 — обычный, 2 — в фокусе.
Если нужен конкретный цвет, можно не брать его из палитры, а задать сам:
`color::attr(14, 1)` — жёлтый на синем.

### События

```rust,ignore
fn handle_event(&mut self, ev: &mut Event, ctx: &mut Ctx) {
    view::default_handle_event(&self.vs, ev, ctx);
    match ev {
        Event::MouseDown(_) => { self.value += 1; ev.clear(); }
        Event::KeyDown(k) if self.vs.is_focused() => {
            match k.key {
                Key::Char(' ') | Key::Enter => self.value += 1,
                Key::Char('-') => self.value -= 1,
                Key::Char('0') => self.value = 0,
                _ => return,
            }
            ev.clear();
        }
        _ => {}
    }
}
```

* Первой строкой вызываем **стандартное поведение**: щелчок по
  представлению переводит на него фокус.
* `Event` — перечисление: `KeyDown` (клавиша), `MouseDown` (нажата кнопка
  мыши), `Command` (команда) и другие.
* `k.key` — какая клавиша: `Key::Char(c)` для букв и знаков, `Key::Enter`,
  `Key::Up`, `Key::F(5)` и т. д.; `k.mods` — зажатые Shift/Ctrl/Alt.
* **Чужие клавиши не трогаем** (`_ => return`) — иначе перестанет
  работать Tab, Alt+X и всё остальное.
* Своё обработали — `ev.clear()`.

`ctx` — «связь с внешним миром»: через него представление может послать
команду (`ctx.post_command`), закрыть окно, открыть диалог. В этом
уроке он не нужен; о нём — в [справочнике](22-views.md#ctx).

## Как представление получает события

* **Клавиши** идут только представлению **в фокусе** — тому, что
  выбрано в активном окне. Поэтому в коде проверка
  `if self.vs.is_focused()`.
* **Мышь** идёт тому, над кем курсор.
* Если представление не обработало событие (не вызвало `clear`), его
  получают другие: окно, программа, обработчик приложения.

## Попробуйте

1. Сделайте счётчик шире и нарисуйте полоску: `'█'` столько раз, каково
   значение (`dc.write_char(x, 0, '█', color, self.value)`).
2. Добавьте клавиши ↑ и ↓ (`Key::Up`, `Key::Down`).
3. Положите счётчик в диалог из урока 5 и добавьте ему обмен данными:
   методы `has_data` (вернуть `true`), `get_data` (`Value::Int(self.value
   as i64)`) и `set_data`. Пример — в [справочнике](22-views.md#view).

## Важно запомнить

* Представление = структура с `vs: ViewState` + `impl View` с
  `impl_view_basics!()`, `draw` и (обычно) `handle_event`.
* В `draw` координаты свои, от `(0, 0)`; закрашивайте всю область.
* Цвета — номерами через `palette()`, удобно взять палитру похожего
  элемента.
* Клавиши — только в фокусе; чужие клавиши не трогайте; своё — `clear()`.
