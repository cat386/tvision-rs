# Справочник: события, клавиши, команды

Программа с интерфейсом всё время ждёт, что сделает пользователь. Каждое
его действие — нажатие клавиши, щелчок, выбор пункта меню — превращается
в **событие**, и программа передаёт его тому, кому оно предназначено.

## `Event` — событие

**Что это.** Перечисление: что именно произошло.

| Вариант | Что произошло |
|---------|---------------|
| `KeyDown(KeyEvent)` | нажата клавиша |
| `MouseDown(m)` | нажата кнопка мыши |
| `MouseUp(m)` | кнопка отпущена |
| `MouseMove(m)` | мышь сдвинулась |
| `MouseAuto(m)` | кнопка удерживается (событие повторяется — для прокрутки) |
| `MouseWheel(m)` | повёрнуто колесо |
| `Command(Message)` | команда: из меню, от кнопки, от строки состояния |
| `Broadcast(Message)` | сообщение «всем»: одно представление сообщает соседям, что что-то изменилось |
| `Nothing` | пусто: событие уже обработано |

**Аналог:** `TEvent`.

**Как обрабатывать.** В методе `handle_event` своего представления или
обработчика приложения:

```rust
use tvision::*;

/// Возвращает, что сделали, — для проверки.
fn handle(ev: &mut Event) -> &'static str {
    // Клавиша?
    if let Some(k) = ev.key() {
        if k.is(kb::F2) {
            ev.clear(); // обработано — дальше не пойдёт
            return "F2";
        }
    }
    // Команда?
    if ev.command() == Some(cm::OK) {
        ev.clear();
        return "OK";
    }
    "не наше"
}

fn check() {
    let mut e = Event::KeyDown(kb::F2);
    assert_eq!(handle(&mut e), "F2");
    assert!(e.is_nothing()); // после clear событие пустое
    let mut c = Event::command_event(cm::OK);
    assert_eq!(handle(&mut c), "OK");
}
```

| Метод | Что делает |
|-------|-----------|
| `clear()` | «я обработал»: событие становится пустым и дальше не идёт |
| `is_nothing()` | обработано ли уже |
| `key()` | клавиша, если это нажатие клавиши |
| `command()` | номер команды, если это команда |
| `broadcast()` | сообщение, если это `Broadcast` |
| `mouse()`, `mouse_mut()` | данные мыши, если это событие мыши |
| `is_mouse()` | событие ли мыши |
| `Event::command_event(cmd)` | создать команду (например, для `app.put_event`) |

**Что важно знать.** Своё событие — `ev.clear()`. Чужое — не трогайте:
просто выйдите из функции, и его получит кто-то другой.

## `Key` — клавиша

**Что это.** Какая клавиша нажата (без Shift/Ctrl/Alt):

| Вариант | Клавиша |
|---------|---------|
| `Char(c)` | буква, цифра, знак, пробел — в той раскладке, что включена |
| `Enter`, `Esc`, `Tab`, `Backspace` | |
| `BackTab` | Shift+Tab (некоторые терминалы присылают его так) |
| `Up`, `Down`, `Left`, `Right` | стрелки |
| `Home`, `End`, `PgUp`, `PgDn`, `Ins`, `Del` | |
| `F(n)` | F1–F12: `Key::F(5)` |

## `Mods` — Shift, Ctrl, Alt

**Что это.** Какие клавиши-модификаторы зажаты: поля `shift`, `ctrl`,
`alt`. Готовые значения: `Mods::NONE`, `Mods::SHIFT`, `Mods::CTRL`,
`Mods::ALT`, `Mods::CTRL_SHIFT`.

## `KeyEvent` — нажатие клавиши

**Что это.** Клавиша и модификаторы: поля `key` и `mods`.

```rust
use tvision::*;

fn keys() {
    let k = KeyEvent::new(Key::Char('x'), Mods::ALT); // Alt+X
    assert!(k.is(kb::ALT_X)); // большие и маленькие буквы не различаются
    assert_eq!(k.name(), "Alt+X"); // для подписей
    assert_eq!(k.text_char(), None); // с Alt — это не ввод текста

    let t = KeyEvent::new(Key::Char('ж'), Mods::NONE);
    assert_eq!(t.text_char(), Some('ж')); // обычная буква — ввод текста
}
```

| Метод | Что делает |
|-------|-----------|
| `KeyEvent::new(клавиша, модификаторы)` | создать |
| `is(другое)` | то же ли это сочетание |
| `text_char()` | символ, если это обычный ввод текста (без Ctrl и Alt) |
| `alt_char()` | буква для Alt+буква |
| `name()` | название: `"Alt+X"`, `"Ctrl+F5"`, `"F10"` |

## `kb` — готовые клавиши

Константы и функции для частых сочетаний:

| Что | Как записать |
|-----|-------------|
| клавиша без модификаторов | `kb::key(Key::Ins)` |
| Alt+буква, Ctrl+буква | `kb::alt('X')`, `kb::ctrl('N')` |
| F1–F12 | `kb::f(9)`; готовые `kb::F1`, `F2`, `F3`, `F5`, `F6`, `F10` |
| Alt+F, Ctrl+F, Shift+F | `kb::alt_f(3)`, `kb::ctrl_f(5)`, `kb::shift_f(6)` |
| частые | `kb::ENTER`, `kb::ESC`, `kb::TAB`, `kb::SHIFT_TAB`, `kb::ALT_X`, `kb::ALT_F3`, `kb::CTRL_F5`, `kb::SHIFT_F6` |

> Некоторые Ctrl+буква терминал присылает как другие клавиши: Ctrl+J и
> Ctrl+M — это Enter, Ctrl+I — Tab, Ctrl+H — Backspace. Не назначайте на
> них команды — они не будут работать.

## `MouseEvent` — мышь

**Что это.** Где мышь и что с кнопками.

| Поле | Что |
|------|-----|
| `pos` | где курсор — **в координатах владельца** представления; свои координаты — `self.vs.make_local(m.pos)` |
| `buttons` | какие кнопки нажаты: `event::MB_LEFT`, `MB_RIGHT`, `MB_MIDDLE` (биты) |
| `double` | двойной щелчок |
| `mods` | зажаты ли Shift, Ctrl, Alt |
| `wheel` | колесо: −1 — вверх, +1 — вниз |

```rust
use tvision::event::MB_RIGHT;
use tvision::*;

/// Где щёлкнули правой кнопкой — в своих координатах.
fn right_click(vs: &ViewState, ev: &Event) -> Option<Point> {
    match ev {
        Event::MouseDown(m) if m.buttons & MB_RIGHT != 0 => Some(vs.make_local(m.pos)),
        _ => None,
    }
}
```

Константы `MB_…` лежат в модуле `tvision::event` — их подключают
отдельно: `use tvision::event::MB_RIGHT;`.

## `Message` и `Info` — команда с данными

**`Message`** — что лежит внутри `Command` и `Broadcast`: номер команды
`command` и данные `info`.

**`Info`** — данные команды. Обычно их нет (`Info::None`), но иногда
нужно сказать «кто послал» или передать число:

| Вариант | Когда встречается |
|---------|-------------------|
| `None` | большинство команд |
| `Id(ViewId)` | кто послал: «в этом списке выбрали строку» |
| `Int(i64)`, `Str(String)` | свои данные |
| `Text { id, text }`, `Indicator { … }`, `Progress { id, value }`, `Scroll { … }` | служебные сообщения элементов друг другу |

```rust
use tvision::*;

/// Какой список сообщил «выбрана строка».
fn selected_list(ev: &Event) -> Option<ViewId> {
    match ev.broadcast() {
        Some(Message { command: cm::LIST_ITEM_SELECTED, info: Info::Id(id) }) => Some(*id),
        _ => None,
    }
}
```

## `cm` — стандартные команды

Модуль `cm` — команды библиотеки. Их не нужно обрабатывать самим: их
понимают окна, диалоги, рабочий стол, редактор. Достаточно поставить в
меню.

| Что | Команды |
|-----|---------|
| программа и окна | `QUIT` (выход), `MENU` (открыть меню), `CLOSE`, `ZOOM` (распахнуть), `RESIZE`, `NEXT`, `PREV`, `TILE` (мозаика), `CASCADE` (каскад), `HELP` |
| ответы диалога | `OK`, `CANCEL`, `YES`, `NO` — закрывают диалог |
| правка (для редактора и полей) | `CUT`, `COPY`, `PASTE`, `UNDO`, `REDO`, `CLEAR`, `FIND`, `REPLACE`, `SEARCH_AGAIN`, `SELECT_ALL` |
| файлы (для редактора) | `NEW`, `OPEN`, `SAVE`, `SAVE_AS` |
| сообщения элементов | `LIST_ITEM_SELECTED`, `TABLE_CURSOR_MOVED`, `TREE_CURSOR_MOVED`, `SCROLL_BAR_CHANGED`, `RECEIVED_FOCUS`… |

Все команды с номерами — [глава 16](../16-reference.md#cm--команды).

**Свои команды** нумеруйте от **100**. Если команду нужно уметь
запрещать (делать пункт меню серым), её номер должен быть не больше
**255**.

## Куда попадает событие

Это полезно знать, когда событие «не доходит».

1. **Клавиши и команды** идут по цепочке **фокуса**: программа → рабочий
   стол → активное окно → элемент в фокусе. Кто первый обработал
   (`clear`), тот и забрал.
   * Строка состояния и строка меню видят клавиши **раньше** всех —
     поэтому их клавиши работают везде, даже в диалогах.
   * Кнопка «по умолчанию» видит Enter **после** элемента в фокусе: если
     поле Enter не забрало, нажмётся кнопка.
2. **Мышь** идёт тому, кто под курсором (самому верхнему).
3. **Сообщения** (`Broadcast`) получают все **соседи** отправителя —
   другие дети его окна или диалога.
4. Если **команду** никто не обработал, она приходит в
   `AppHandler::handle_event` — в ваш обработчик приложения.

```text
  клавиша F2
     │
     ▼
  строка состояния ── есть пункт с F2? ──► посылает команду CM_HELLO
     │                                              │
     ▼                                              ▼
  рабочий стол → окно → поле в фокусе      окна → … → AppHandler
```
