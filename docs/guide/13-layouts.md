# Урок 13. Раскладки: без координат

В [уроке 4](04-coordinates.md) каждый элемент диалога ставился
прямоугольником: `Rect::new(x, y, x + ширина, y + высота)`. Это точно, но
утомительно: добавили поле — сдвигайте всё, что ниже; поменяли подпись
— пересчитывайте отступы; растянули окно — подбирайте `grow_mode`.

В Qt для этого есть **раскладки** (layouts): вы говорите «эти элементы —
в строку, эти — в столбец, а здесь — пружина», а координаты библиотека
считает сама. В `tvision-rs` то же самое — модуль `tvision::layout`.

Программа урока: `cargo run --example layout_demo`.

## Четыре вида раскладок

| Раскладка | Как в Qt | Что делает |
|-----------|----------|-----------|
| `HBox` | `QHBoxLayout` | элементы в строку, слева направо |
| `VBox` | `QVBoxLayout` | элементы в столбец, сверху вниз |
| `Grid` | `QGridLayout` | сетка: строки и столбцы, элемент может занимать несколько клеток |
| `Form` | `QFormLayout` | строки «подпись — поле»: подписи в столбец по самой длинной, поля — дальше |

И распорки, как `QSpacerItem`:

| Что | Как в Qt | Что делает |
|-----|----------|-----------|
| `.stretch(1)` | `addStretch(1)` | **пружина**: забирает всё лишнее место |
| `.space(2)` | `addSpacing(2)` | пустое место ровно в 2 клетки |
| `Spacer::horizontal()`, `Spacer::vertical()`, `Spacer::fixed(w, h)` | `QSpacerItem` | распорка для сетки и особых случаев |

Раскладки вкладываются друг в друга: в столбце может быть строка, в
строке — столбец, и так сколько угодно.

## Первая раскладка: диалог входа

```rust,ignore
use tvision::layout::*;
use tvision::*;

fn login() -> Dialog {
    let mut d = Dialog::centered(30, 10, "Вход");          // размер — пока любой

    // Элементы — с пустым прямоугольником: место им найдёт раскладка.
    let user = d.add(InputLine::new(Rect::default(), 30));
    let pass = d.add(InputLine::new(Rect::default(), 30));
    let lu = d.add(Label::new(Rect::default(), "~И~мя:", Some(user)));
    let lp = d.add(Label::new(Rect::default(), "~П~ароль:", Some(pass)));
    let ok = d.add(Button::new(Rect::default(), "O~K~", cm::OK, bf::DEFAULT));
    let cancel = d.add(Button::new(Rect::default(), "Отмена", cm::CANCEL, bf::NORMAL));

    d.set_layout(
        VBox::new()                                       // всё — в столбец:
            .margins(2, 1, 2, 0)                          //   поля: слева 2, сверху 1, справа 2
            .add(Form::new().row(lu, user).row(lp, pass)) //   форма из двух строк
            .space(1)                                     //   пустая строка
            .add(HBox::new()                              //   и ряд кнопок:
                .stretch(1)                               //     пружина слева — кнопки вправо
                .add(ok)
                .add(cancel)),
    );
    d.adjust_size();                                      // размер диалога — по содержимому
    d
}
```

Получится:

```text
╔═[■]═════════════ Вход ═════════════════╗
║                                        ║
║  Имя:     ████████████████████████████ ║
║                                        ║
║  Пароль:  ████████████████████████████ ║
║                                        ║
║                     OK   ▄  Отмена ▄   ║
║                    ▀▀▀▀▀▀▀▀ ▀▀▀▀▀▀▀▀   ║
╚════════════════════════════════════════╝
```

Что здесь важно:

* **`Rect::default()`** — пустой прямоугольник. Положение и размер
  элементам даст раскладка, поэтому считать координаты не нужно.
* **`d.set_layout(…)`** — поставить раскладку. Она сразу расставит
  элементы и потом будет делать это **при каждом изменении размера**
  окна.
* **`d.adjust_size()`** — подогнать размер диалога под содержимое (как
  `adjustSize()` в Qt). Поэтому в `Dialog::centered(30, 10, …)` размер
  можно написать любой.
* Добавить ещё одно поле — значит дописать `.row(подпись, поле)`. Всё
  остальное сдвинется само.

## Откуда берутся размеры

Каждый элемент знает свой **желаемый размер** — как `sizeHint()` в Qt:

| Элемент | Желаемый размер |
|---------|-----------------|
| `Button` | по надписи + 4, не меньше 10; высота 2 |
| `Label` | по тексту; высота 1 |
| `StaticText` | по самой длинной строке × число строк |
| `InputLine` | по длине (не больше 30); высота 1 |
| флажки, переключатели | по самому длинному пункту × число пунктов |
| таблица, список, редактор, дерево | размер, с которым создан (или 10 × 3) |

…и как он относится к лишнему месту — **политику** (`Policy`, как
`QSizePolicy`):

| Политика | Что значит | У кого по умолчанию |
|----------|-----------|---------------------|
| `Fixed` | ровно желаемый размер | кнопка (обе стороны), высота строки ввода и подписи |
| `Preferred` | желаемый лучше всего, но может расти | ширина подписи, флажков |
| `Expanding` | хочет как можно больше | ширина строки ввода; таблица, список, редактор — в обе стороны |
| `Minimum`, `Maximum`, `Ignored` | не меньше / не больше желаемого / размер не важен | — |

**Как делится лишнее место в строке:**

1. Если у кого-то задан **коэффициент растяжения** (`stretch`) — место
   делится по коэффициентам. Пружина `.stretch(1)` — это пустое место с
   коэффициентом 1.
2. Иначе — тем, у кого `Expanding` (строка ввода, таблица).
3. Иначе — всем, кто может расти.

Если места **не хватает**, сжимаются те, кому можно, — но не меньше их
минимума. Окно с раскладкой нельзя сделать меньше её минимума: рамка
просто не потянется.

## Пропорции: окно «Почта»

Папки слева — четверть ширины, письма и текст справа — три четверти;
кнопки внизу справа:

```rust,ignore
w.set_layout(
    VBox::new()
        .add(HBox::new()
            .add(item(folders).stretch(1))                // 1 часть ширины
            .add(item(VBox::new()
                    .spacing(1)
                    .add(item(letters).stretch(2))        // 2/3 высоты
                    .add(item(text).expand().stretch(1))) // 1/3 высоты
                .stretch(3)))                             // 3 части ширины
        .space(1)
        .add(HBox::new().stretch(1).add(reply).add(delete)),
);
```

**`item(…)`** заворачивает элемент, чтобы что-то уточнить:

| Уточнение | Что делает |
|-----------|-----------|
| `.stretch(n)` | коэффициент растяжения |
| `.expand()` | тянуться во все стороны (политика `Expanding`) |
| `.fixed(w, h)`, `.fixed_width(w)`, `.fixed_height(h)` | ровно такой размер |
| `.min(w, h)`, `.max(w, h)`, `.min_width(w)`… | пределы |
| `.hint(w, h)` | свой желаемый размер |
| `.policy(по_ширине, по_высоте)` | своя политика |
| `.align_h(Alignment::…)`, `.align_v(…)`, `.center()` | не растягивать, а поставить в начало / по центру / в конец |

Растяните окно мышью за правый нижний угол (или Ctrl+F5 и стрелки с
Shift) — пропорции сохраняются, кнопки остаются в углу.

## Сетка: калькулятор

```rust,ignore
let mut grid = Grid::new()
    .span(0, 0, 1, 3, display)          // табло: строка 0, столбец 0, на 1 строку и 3 столбца
    .cell(0, 3, clear);                 // «C» — в четвёртом столбце
for (i, b) in buttons.iter().enumerate() {
    grid = grid.cell(1 + i / 4, i % 4, item(*b).expand());  // кнопки заполняют клетки
}
for c in 0..4 { grid = grid.col_stretch(c, 1); }    // столбцы поровну
for r in 1..5 { grid = grid.row_stretch(r, 1); }    // строки с кнопками поровну
w.set_layout(grid.margins(1, 0, 1, 0));
```

* `.cell(строка, столбец, элемент)` — в одну клетку;
* `.span(строка, столбец, строк, столбцов, элемент)` — на несколько;
* `.col_stretch(столбец, n)`, `.row_stretch(строка, n)` — как делить
  лишнее место между столбцами и строками.

Кнопкам задано `.expand()`: обычно кнопка не меняет размер (`Fixed`), а
здесь пусть растёт вместе с окном.

## Промежутки и поля

| Раскладка | Промежуток по умолчанию |
|-----------|------------------------|
| `HBox` | 1 клетка между элементами |
| `VBox` | 0 — строки вплотную |
| `Grid` | 1 между столбцами, 0 между строками |
| `Form` | 1 между подписью и полем, **1 между строками** (как в диалогах Turbo Vision) |

Поменять: `.spacing(n)` (а у сетки отдельно `.hspacing(n)` и
`.vspacing(n)`). Поля вокруг: `.margins(слева, сверху, справа, снизу)`
или `.margin(n)`. Рамку окна раскладка учитывает сама.

Рядом с распорками промежуток не ставится — как в Qt. Поэтому `.space(2)`
даёт ровно 2 клетки.

## Скрыть и показать

Скрытый элемент места **не занимает** — остальные сдвигаются:

```rust,ignore
if let Some(v) = d.win.group.view_mut(details) {
    v.vs_mut().state &= !sf::VISIBLE;              // скрыть
}
d.win.group.apply_layout();                        // пересчитать
d.adjust_size();                                   // и подогнать окно, если нужно
```

`apply_layout()` нужен и после других изменений, от которых меняется
желаемый размер: например, сменили надпись кнопки.

## Раскладка и `grow_mode` вместе

Раскладка управляет только теми элементами, которые в неё добавлены.
Остальные (например, полосы прокрутки на рамке окна) двигаются по своему
`grow_mode`, как раньше. Раскладку можно поставить и в любую группу —
`group.set_layout(…)`; тогда отступа под рамку нет.

## Попробуйте

1. В диалог входа добавьте поле «Сервер» с переключателями:
   `Cluster::radio_buttons(Rect::default(), &["~Р~абочий", "~Д~омашний"])`
   и строку `.row(подпись, переключатели)`. Ничего пересчитывать не
   придётся.
2. Поставьте кнопки по центру: пружина и слева, и справа —
   `HBox::new().stretch(1).add(ok).add(cancel).stretch(1)`.
3. В «Почте» поменяйте пропорции на 1:1 и растяните окно.
4. Сделайте в калькуляторе кнопку «0» шириной в две клетки:
   `.span(4, 0, 1, 2, ноль)`.

## Важно запомнить

* Элементы создаются с `Rect::default()`, место им даёт раскладка.
* `HBox` — строка, `VBox` — столбец, `Grid` — сетка, `Form` — «подпись —
  поле»; вкладываются друг в друга.
* `.stretch(n)` — пружина, `.space(n)` — ровно `n` клеток.
* `item(элемент)` — уточнить: `.stretch()`, `.expand()`, `.fixed()`,
  `.align_h()`…
* `set_layout` — раскладка пересчитывается при каждом изменении размера
  окна; `adjust_size` — размер окна по содержимому.
