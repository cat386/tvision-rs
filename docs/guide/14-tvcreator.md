# Урок 14. TVCreator: формы мышью

В [уроке 13](13-layouts.md) окна собирались из раскладок в коде. Это
удобнее координат, но всё равно приходится запускать программу, чтобы
увидеть результат. В Qt для этого есть Qt Designer: форму рисуют мышью,
сохраняют в файл `.ui`, а `uic` превращает её в код.

У `tvision-rs` для этого есть **TVCreator**:

```text
cargo run -p tvcreator
```

Подробное описание всех возможностей — в
[`tools/tvcreator/README.md`](../../tools/tvcreator/README.md).

## Что на экране

| Место | Что там | Как в Qt |
|-------|---------|----------|
| слева вверху — **Виджеты** | раскладки, пружина, промежуток и виджеты | Widget Box |
| слева внизу — **Объекты** | дерево формы | Object Inspector |
| в центре — **Форма** | живой вид формы: настоящие виджеты | форма |
| справа — **Свойства** | свойства выбранного | Property Editor |

Между частями — **Tab**.

## Соберём диалог входа

1. **Форма.** В дереве объектов встаньте на верхнюю строку («Form1 —
   Dialog») и в свойствах поменяйте «Имя типа» на `LoginDialog`, а
   «Заголовок» — на `Вход` (Enter на строке свойства, ввести, Enter).
2. **Подписи и поля.** В палитре выберите «Форма (Form)» — Enter. Новая
   раскладка выделена; добавьте в неё «Подпись», затем «Строку ввода».
   Подпись сама подписывает поле, которое добавили сразу после неё (как
   buddy в Qt). Ещё раз «Подпись» и «Строка ввода» — вторая строка формы.
3. **Тексты и имена.** Щёлкните по подписи на форме — справа её
   свойства: текст `~И~мя:`. У строки ввода — имя `user` (имя переменной
   в коде). Так же `~П~ароль:` и `pass`.
4. **Кнопки.** Выделите в дереве корневой `VBox` и добавьте «Пружину» —
   она прижмёт кнопки к низу. Потом «Строку (HBox)», в неё «Пружину»,
   «Кнопку», «Кнопку». У первой кнопки — надпись `O~K~`, команда `OK`,
   «По умолчанию» — да; у второй — `Отмена` и `CANCEL`.
5. **Посмотрите** — **Ctrl+R**: диалог как в программе. Esc — закрыть.
6. **Сохраните** — **F2**, например в `login.tvui`.
7. **Код** — **F9**: рядом с формой появится `login_dialog.rs`.
   Посмотреть его, ничего не записывая, — **F7**.

Ошиблись — **Ctrl+Z**. Не туда добавили — **Ctrl+↑ / Ctrl+↓** или **Del**.
Хотите кнопки в отдельной строке — выделите кнопку и «Раскладка →
Обернуть в строку».

Разделить форму на части — **«Линия»**: горизонтальная тянется по
ширине, вертикальная — по высоте; свойство «До рамки окна» протянет её
от рамки до рамки. Линии сами соединяются с рамкой и друг с другом
(`╟───┬───╢`) — посмотрите образец `tools/tvcreator/forms/props.tvui`.

## Темы

Меню **Тема → Среда** меняет цвета самого TVCreator (**Ctrl+T** — выбор с
предпросмотром), а **Тема → Форма на холсте** показывает форму в цветах
темы, в которой её увидят пользователи, — не трогая цвета среды.
Предпросмотр (Ctrl+R) тоже идёт в теме формы. Темы — файлы `.tvtheme` из
каталога `themes/` (о них — [урок 15](15-themes.md)); выбор запоминается
до следующего запуска.

**Файл → Настройки…** — стандартный диалог настроек из
[урока 16](16-settings.md): тема среды, цвета терминала, фон, язык,
мышь. Настройки хранятся в `tvcreator.settings.json` рядом с программой.

## Код в программе

```rust,ignore
mod login_dialog;                       // файл из TVCreator
use login_dialog::LoginDialog;

fn ask_login(app: &mut Program) -> Option<String> {
    let (d, ui) = LoginDialog::create();
    let (cmd, d) = app.exec_dialog(d);
    if cmd != cm::OK {
        return None;
    }
    // ui — структура с id всех виджетов формы.
    d.win.group.find::<InputLine>(ui.user).map(|l| l.text())
}
```

Сгенерированный файл **не правят вручную**: при следующей генерации
изменения пропадут. Всё, что нужно менять, меняют в форме; а код,
который работает с формой (обработка кнопок, данные), пишут рядом — как
в уроках 5–9.

Свои команды кнопок (например, `CM_REGISTER`) попадают в код
константами — их можно ловить в `AppHandler` или в `app.modal_hook`.

## Форма как исходник

Файл `.tvui` — JSON, его удобно хранить в git и смотреть в диффах. Код из
него можно получать при каждой сборке, как `uic` в CMake: через
`build.rs` и `tvcreator::codegen::generate_for_include` (пример — в
[README TVCreator](../../tools/tvcreator/README.md#генерация-при-сборке-buildrs)).
Без среды, из командной строки:

```text
cargo run -p tvcreator -- --gen forms/login.tvui -o src/login_dialog.rs
```

## Попробуйте

1. Откройте образец: `cargo run -p tvcreator -- tools/tvcreator/forms/login.tvui`.
   Поменяйте у кнопки «Отмена» растяжение на 1 — посмотрите, что стало с
   кнопками.
2. Сделайте форму «Почта» как в уроке 13: `HBox` с двумя элементами,
   у списка растяжение 1, у вложенного `VBox` — 3. Поменяйте вид формы
   на `Window` и снимите «Размер по содержимому».
3. Сетка: калькулятор 3 × 4, у кнопок «Тянуться во все стороны» — да.

## Важно запомнить

* TVCreator — это Qt Designer для tvision-rs: палитра, дерево, форма,
  свойства.
* Форма хранится в `.tvui`; **F9** или `tvcreator --gen` дают код.
* В коде — структура с id всех виджетов и `create()`.
* Сгенерированный код не правят; меняют форму и генерируют заново.
* Меню «Тема»: цвета среды и, отдельно, цвета формы на холсте.

Следующий урок — [темы](15-themes.md): цвета программы в отдельном файле.
