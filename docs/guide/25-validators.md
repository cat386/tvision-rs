# Справочник: проверка ввода

**Валидатор** следит, чтобы в строку ввода попадало только правильное:
цифры в поле «Возраст», дата в формате `дд.мм.гггг`, слово из списка.
Его прикрепляют к строке: `InputLine::new(…).with_validator(…)`.

## Как это работает

Валидатор проверяет в два момента:

1. **Пока набирают.** Неправильный символ просто не появляется (например,
   буква в поле для цифр). Маска может сама дописать точки и скобки.
2. **Когда нажимают OK.** Если значение не подходит (число вне диапазона,
   дата не до конца), появляется сообщение, курсор возвращается в поле, а
   диалог остаётся открытым. «Отмена» и Esc проверку не запускают.

```rust
use tvision::*;

fn fields(d: &mut Dialog) {
    // Дата: маска, точки дописываются сами.
    d.add(InputLine::new(Rect::new(3, 2, 15, 3), 10).with_validator(PictureValidator::new("##.##.####", true)));
    // Шестнадцатеричное число: только эти символы.
    d.add(InputLine::new(Rect::new(3, 4, 15, 5), 8).with_validator(FilterValidator::new("0123456789ABCDEFabcdef")));
    // Целое от 1 до 100.
    d.add(InputLine::new(Rect::new(3, 6, 15, 7), 3).with_validator(RangeValidator::new(1, 100)));
    // Одно из двух слов.
    d.add(InputLine::new(Rect::new(3, 8, 15, 9), 10).with_validator(StringLookupValidator::new(&["да", "нет"])));
}
```

**Аналоги:** `TValidator` и его наследники.

## `FilterValidator` — только разрешённые символы

**Что это.** Пропускает только символы из заданного набора — остальные
не набираются.

**Когда нужен.** Телефоны, коды, числа без проверки диапазона.

```rust
use tvision::*;

fn filter() {
    let v = FilterValidator::new("0123456789+-() ");
    let mut good = "+7 (900)".to_string();
    assert!(v.is_valid_input(&mut good, false));
    let mut bad = "+7 abc".to_string();
    assert!(!v.is_valid_input(&mut bad, false)); // буквы не пройдут
}
```

Набор символов — поле `valid_chars`.

## `RangeValidator` — число в диапазоне

**Что это.** Целое от `min` до `max`. Пока набирают, пропускает только
цифры (и минус, если `min` меньше нуля); при OK проверяет диапазон.

```rust
use tvision::*;

fn range() {
    let v = RangeValidator::new(1, 100);
    assert!(v.is_valid("42"));
    assert!(!v.is_valid("0"));
    assert!(!v.is_valid("101"));
}
```

**Что важно знать.** Значение поля остаётся **строкой** (`Value::Str`).
Если нужно сразу число, удобнее [`InputLong`](26-controls.md#inputlong--поле-для-числа).

## `PictureValidator` — маска

**Что это.** Значение должно соответствовать **маске**: `##.##.####` —
две цифры, точка, две цифры, точка, четыре цифры. Второй аргумент —
`true`: точки, скобки и другие постоянные символы дописываются сами.

```rust
use tvision::*;

fn masks() {
    let date = PictureValidator::new("##.##.####", true);
    assert!(date.is_valid("05.11.2026"));
    assert!(!date.is_valid("05.11")); // не до конца
    assert!(!date.is_valid("ab.11.2026")); // не цифры

    let yes_no = PictureValidator::new("{Да,Нет}", true); // одно из слов
    assert!(yes_no.is_valid("Да"));

    let broken = PictureValidator::new("[##", false); // ошибка в самой маске
    assert!(!broken.status_ok());
}
```

**Символы маски:**

| Символ | Значит |
|--------|--------|
| `#` | цифра |
| `?` | буква |
| `&` | буква, станет заглавной |
| `@` | любой символ |
| `!` | любой символ, станет заглавным |
| `*` | повтор: `*3#` — три цифры, `*#` — сколько угодно цифр |
| `[ ]` | необязательная часть: `#[#]` — одна или две цифры |
| `{ }` | группа |
| `,` | «или»: `{Да,Нет}` |
| `;` | следующий символ — как есть: `;#` — сам знак «#» |
| всё остальное | постоянный символ (точка, скобка, дефис) |

**Готовые маски:**

| Маска | Для чего |
|-------|---------|
| `##.##.####` | дата `05.11.2026` |
| `(###) ###-##-##` | телефон |
| `#[#][#]` | число из 1–3 цифр |
| `&*?` | слово с заглавной буквы: «иван» → «Иван» |
| `*#[.##]` | число с необязательными двумя знаками после точки |

**Что важно знать.** Пустое значение маску **не проходит**. Если поле
необязательное, используйте `FnValidator` с проверкой
`s.is_empty() || …`.

**Реже:** `picture(&mut строка, дописывать) -> PicResult` — разобрать
строку по маске самому; `status_ok()` — правильна ли маска; текст ошибки
— `validate::PICTURE_ERROR`.

## `PicResult`

Результат разбора маски: `Complete` (строка полностью подходит),
`Incomplete` (подходит, но не до конца — можно продолжать набор),
`Empty`, `Error` (не подходит), `Syntax` (ошибка в самой маске),
`Ambiguous`, `IncompNoFill`.

## `StringLookupValidator` — значение из списка

**Что это.** При OK проверяет, что введено одно из разрешённых значений:
`StringLookupValidator::new(&["да", "нет"])`. Набирать можно что угодно
— проверяется только итог. Список — поле `strings`.

Если хочется **выбирать** из списка, а не печатать, — возьмите
[`Combo`](26-controls.md#combo--выпадающий-список) с флагом `cbx::ONLY_LIST`.

## `FnValidator` — своя проверка функцией

**Что это.** Проверка любой функцией: `f` получает текст и возвращает
`true`, если всё хорошо; `message` — что сказать, если нет. Срабатывает
при OK.

**Когда нужен.** Почти всегда, когда готовые не подходят: «не пусто»,
«есть @», «файл существует».

```rust
use tvision::*;

fn email() -> InputLine {
    InputLine::new(Rect::new(3, 2, 40, 3), 60).with_validator(FnValidator {
        f: |s: &str| s.is_empty() || (s.contains('@') && s.contains('.')),
        message: "Введите адрес вида имя@домен.ru".into(),
    })
}
```

## `Validator` — свой валидатор

**Что это.** Трейт, который реализуют все валидаторы. Свой нужен, если
надо проверять и **по ходу набора** (`FnValidator` проверяет только при
OK) или исправлять ввод.

| Метод | Когда | Что вернуть |
|-------|-------|------------|
| `is_valid_input(&self, s, suppress_fill)` | после каждого нажатия | `false` — отменить нажатие; можно изменить `s` |
| `is_valid(&self, s)` | при OK | `false` — показать сообщение |
| `error_message(&self)` | для сообщения | текст ошибки (обязательный метод) |
| `status_ok(&self)` | при создании окна | правилен ли сам валидатор |

`suppress_fill = true` приходит, когда пользователь **стирает**: в этот
момент ничего не дописывайте, иначе стереть не получится.

```rust
use tvision::*;

/// Логин: латиница и цифры, 3–16 символов, всегда маленькими буквами.
struct Login;

impl Validator for Login {
    fn is_valid_input(&self, s: &mut String, _suppress_fill: bool) -> bool {
        *s = s.to_lowercase(); // исправляем ввод на лету
        s.chars().all(|c| c.is_ascii_alphanumeric()) && s.chars().count() <= 16
    }
    fn is_valid(&self, s: &str) -> bool {
        (3..=16).contains(&s.chars().count())
    }
    fn error_message(&self) -> String {
        "Логин: от 3 до 16 латинских букв и цифр".into()
    }
}

fn login() {
    let mut s = "Ivan".to_string();
    assert!(Login.is_valid_input(&mut s, false));
    assert_eq!(s, "ivan");
    assert!(!Login.is_valid("iv")); // короче трёх
    let _field = InputLine::new(Rect::new(3, 2, 22, 3), 16).with_validator(Login);
}
```
