# Урок 5. Первый диалог

Диалог — окно с полями и кнопками, которое что-то спрашивает у
пользователя. Сделаем самый простой: «Как вас зовут?» — и поздороваемся
по имени.

## Программа

Файл `examples/learn_05_dialog.rs`:

```rust,ignore
//! Урок 5. Первый диалог: спросить имя и поздороваться.
//!
//! Запуск: `cargo run --example learn_05_dialog`. F2 — диалог, Alt+X — выход.

use tvision::*;

const CM_ASK: u16 = 100;

struct App {
    /// Имя, которое ввели в прошлый раз (диалог предложит его снова).
    name: String,
}

/// Строим диалог «Знакомство». Возвращаем сам диалог и номер (id) строки
/// ввода — по нему потом достанем введённый текст.
fn name_dialog(old_name: &str) -> (Dialog, ViewId) {
    // Диалог 40×9, появится по центру экрана.
    let mut d = Dialog::centered(40, 9, "Знакомство");

    // Строка ввода: столбцы 10..37, строка 2; не длиннее 30 символов.
    let mut input = InputLine::new(Rect::new(10, 2, 37, 3), 30);
    input.set_text(old_name);
    let input_id = d.add(input);

    // Подпись слева. Связываем её со строкой: Alt+И переведёт туда курсор.
    d.add(Label::new(Rect::new(2, 2, 9, 3), "~И~мя:", Some(input_id)));

    // Кнопки. Высота кнопки — 2 строки (вторая — тень).
    d.add(Button::new(Rect::new(6, 5, 18, 7), "O~K~", cm::OK, bf::DEFAULT)); // DEFAULT — нажимается по Enter
    d.add(Button::new(Rect::new(21, 5, 33, 7), "Отмена", cm::CANCEL, bf::NORMAL));

    (d, input_id)
}

impl App {
    fn ask(&mut self, app: &mut Program) {
        let (d, input_id) = name_dialog(&self.name);

        // Показать диалог и ждать, пока его закроют. Пока он открыт, остальная
        // программа «замирает» — это и называется модальным окном.
        // Возвращаются: команда, которой закрыли (OK или Cancel), и сам диалог.
        let (cmd, d) = app.exec_dialog(d);
        if cmd != cm::OK {
            return; // нажали «Отмена» или Esc
        }

        // Диалог ещё у нас в руках — достаём из него строку ввода по id.
        let name = d.win.group.find::<InputLine>(input_id).unwrap().text();
        let name = name.trim().to_string();
        if name.is_empty() {
            message_box(app, "\x03Вы не ввели имя.", mf::WARNING | mf::OK_BUTTON);
        } else {
            message_box(app, &format!("\x03Привет, {}!", name), mf::INFORMATION | mf::OK_BUTTON);
            self.name = name;
        }
    }
}

impl AppHandler for App {
    fn handle_event(&mut self, app: &mut Program, ev: &mut Event) {
        if ev.command() == Some(CM_ASK) {
            self.ask(app);
            ev.clear();
        }
    }
}

fn status() -> Vec<StatusDef> {
    vec![StatusDef::all(vec![StatusItem::new("~F2~ Знакомство", kb::F2, CM_ASK), StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT)])]
}

fn main() -> std::io::Result<()> {
    locale::set_language(locale::Language::Ru);
    let mut app = Program::with_terminal(None, Some(status()))?;
    let mut h = App { name: String::new() };
    app.put_event(Event::command_event(CM_ASK)); // сразу открыть диалог
    app.run(&mut h);
    Ok(())
}
```

Запуск: `cargo run --example learn_05_dialog`. Диалог откроется сразу.
Введите имя и нажмите Enter (или щёлкните «OK»). Esc или «Отмена» —
закрыть без ответа. Нажмите F2 ещё раз — диалог предложит имя, которое вы
ввели в прошлый раз.

## Разбор

### Диалог

```rust,ignore
let mut d = Dialog::centered(40, 9, "Знакомство");
```

`Dialog::centered(ширина, высота, заголовок)` — диалог, который при
показе встанет по центру экрана. В ширину и высоту входит рамка.

### Строка ввода

```rust,ignore
let mut input = InputLine::new(Rect::new(10, 2, 37, 3), 30);
input.set_text(old_name);
let input_id = d.add(input);
```

* `InputLine::new(прямоугольник, наибольшая длина)` — поле для ввода
  одной строки. Высота прямоугольника — 1. Текст длиннее поля
  прокручивается.
* `set_text` — начальный текст. Он будет **выделен**: если сразу начать
  печатать, он заменится.
* **`d.add(…)` возвращает id** — номер элемента. Сохраняем его: по нему
  потом достанем введённый текст.

> Почему id, а не ссылка на поле? После `add` полем владеет диалог, и
> держать на него ссылку Rust не позволит. Номер можно хранить сколько
> угодно и найти по нему поле, когда понадобится.

### Подпись

```rust,ignore
d.add(Label::new(Rect::new(2, 2, 9, 3), "~И~мя:", Some(input_id)));
```

`Label` — подпись, **привязанная** к полю (третий аргумент — id поля).
Щелчок по подписи или Alt+И (горячая буква в тильдах) переводят курсор в
поле. Пока поле в фокусе, подпись подсвечена.

### Кнопки

```rust,ignore
d.add(Button::new(Rect::new(6, 5, 18, 7), "O~K~", cm::OK, bf::DEFAULT));
d.add(Button::new(Rect::new(21, 5, 33, 7), "Отмена", cm::CANCEL, bf::NORMAL));
```

* `Button::new(прямоугольник, надпись, команда, флаги)`. Высота
  прямоугольника — **2**: вторая строка — тень кнопки.
* Нажатая кнопка посылает свою команду. `cm::OK` и `cm::CANCEL` —
  особенные: они **закрывают диалог**.
* `bf::DEFAULT` — кнопка «по умолчанию»: её нажимает Enter. Такая
  кнопка в диалоге одна.
* Esc закрывает диалог так же, как «Отмена».

### Показ диалога и ответ

```rust,ignore
let (cmd, d) = app.exec_dialog(d);
if cmd != cm::OK {
    return;
}
let name = d.win.group.find::<InputLine>(input_id).unwrap().text();
```

* `app.exec_dialog(d)` показывает диалог и **ждёт**, пока его закроют.
  Пока диалог открыт, остальная программа на щелчки не реагирует — это
  **модальное** окно.
* Возвращает пару: **команду**, которой диалог закрыли (`cm::OK` или
  `cm::CANCEL`), и **сам диалог** — уже закрытый, но целый.
* Из закрытого диалога достаём поле по id: `find::<InputLine>(id)`
  ищет среди элементов диалога представление с этим номером и типом
  `InputLine`. `.text()` — введённый текст.

`d.win.group` — «содержимое диалога»: у диалога есть окно `win`, а у
окна — группа `group` с элементами. Запоминать это не нужно: цепочку
`d.win.group.find…` просто копируют.

### Открыть диалог сразу

```rust,ignore
app.put_event(Event::command_event(CM_ASK));
```

`put_event` ставит команду в очередь, как будто её выбрали в меню.
`run` первым делом её обработает — и диалог откроется при запуске.

## Попробуйте

1. Добавьте второе поле «Город» на строке 4 и поздоровайтесь так:
   «Привет, Аня из Тулы!». Не забудьте: диалог придётся сделать выше, а
   кнопки — опустить.
2. Сделайте «OK» недефолтной (`bf::NORMAL`), а «Отмену» — дефолтной.
   Что теперь делает Enter?
3. Вместо своего диалога используйте готовую функцию:
   `input_box(app, "Знакомство", "~И~мя:", &self.name, 30)` — она
   возвращает `Some(текст)` или `None`. Для одного поля это короче.

## Важно запомнить

* `d.add(…)` возвращает id — сохраняйте id полей, из которых потом
  нужно прочитать данные.
* Кнопки: высота 2, `cm::OK` и `cm::CANCEL` закрывают диалог,
  `bf::DEFAULT` — нажимается по Enter.
* `let (cmd, d) = app.exec_dialog(d);` — показать и дождаться;
  данные читаются из возвращённого `d`.
