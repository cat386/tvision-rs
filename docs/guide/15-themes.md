# Урок 15. Темы

Цвета программы на tvision-rs задаёт **палитра приложения** — 135
цветов: рабочий стол, меню, окна, диалоги (подробно — в справочнике,
[«Цвета и палитры»](20-basics.md)). **Тема** — это та же палитра,
сохранённая в отдельный файл `.tvtheme`. Тему делают в редакторе, а
программа подключает её одной строкой — или вовсе без кода, переменной
окружения.

## Редактор тем

```text
cargo run -p tvtheme
```

Слева — **группы** («Рабочий стол», «Меню и строка состояния», «Синее
окно», «Серый диалог»…) и **цвета** в группе («Кнопка по умолчанию»,
«Строка ввода»…). Посередине — сетки **Текст** и **Фон**: щёлкните цвет,
и он сразу появится в **предпросмотре** справа — там меню, окна и диалог
со всеми видами элементов. F5 и F6 — выбор из 256 цветов.

Попробуйте:

1. Группа «Рабочий стол», цвет «Фон»: в сетке «Текст» — бирюзовый, в
   «Фон» — синий.
2. Группа «Серый диалог», «Кнопка по умолчанию»: F6 — фон из 256 цветов.
3. **F4** — имя темы («Моя») и описание.
4. **F2** — сохранить, например в `my.tvtheme`.

Ctrl+T — посмотреть тему на всём редакторе сразу; ещё раз Ctrl+T —
вернуть его цвета. Ctrl+Z — отменить.

Подробности — в [README редактора](../../tools/tvtheme/README.md).

## Подключить тему в программе

```rust,ignore
fn main() -> std::io::Result<()> {
    let mut app = Program::with_terminal(Some(menu()), Some(status()))?;
    if let Err(e) = app.load_theme("my.tvtheme") {
        eprintln!("{}", e);                    // нет файла или в нём ошибка
    }
    app.run(&mut App);
    Ok(())
}
```

`load_theme` читает файл и сразу меняет цвета. Ошибка — с номером строки,
если файл испорчен.

**Без кода.** `Program::with_terminal` сам подключает тему из переменной
окружения `TVISION_THEME`:

```text
TVISION_THEME=my.tvtheme cargo run
```

Так можно попробовать тему в любой программе, ничего в ней не меняя.

## Меню тем и выбор с предпросмотром

Обычно темы кладут в каталог рядом с программой, а пользователь выбирает
в меню. Найти все темы каталога:

```rust,ignore
use tvision::theme::{choose_theme, find_themes, Theme};

let (found, errors) = find_themes("themes");       // (путь, тема) и ошибки чтения
let themes: Vec<Theme> = found.into_iter().map(|(_, t)| t).collect();
```

Готовый диалог выбора — **`choose_theme`**: пока курсор ходит по списку,
вся программа перекрашивается; OK — оставить тему, Отмена — вернуть
прежние цвета:

```rust,ignore
if let Some(i) = choose_theme(app, &themes) {
    self.current = themes[i].name.clone();         // можно запомнить в настройках
}
```

А пункт меню на каждую тему — `app.set_theme(&themes[i])`. Всё вместе —
пример `cargo run --example themes`; в каталоге `themes/` репозитория
пять образцов: «Классическая», «Gruvbox», «Морская», «Матрица»,
«Полночь».

Как форма будет выглядеть в теме, видно ещё в TVCreator: меню **Тема →
Форма на холсте** ([урок 14](14-tvcreator.md#темы)).

## Тема внутри программы

Если отдельный файл не нужен, редактор (**F9**) запишет тему как
Rust-код — константу с палитрой:

```rust,ignore
pub const MY_THEME: &[tvision::color::Attr] = &[ /* 135 цветов */ ];

app.palette = MY_THEME.to_vec();
```

## Что внутри файла

```json
{
  "tvtheme": 1,
  "name": "Моя",
  "description": "",
  "base": "classic",
  "colors": [
    {"index": 1, "item": "Рабочий стол: фон", "color": "cyan/blue"}
  ]
}
```

В файле — только цвета, которые отличаются от **основы** (`base`:
`classic`, `gruvbox`, `blackwhite`, `monochrome`). Цвет —
`текст/фон`: имя (`white`, `lightblue`…), номер из 256 (`221`) или
`#rrggbb`. Файл можно править и руками.

## Попробуйте

1. Запустите пример с темой «Матрица»:
   `TVISION_THEME=themes/matrix.tvtheme cargo run --example themes`.
2. Откройте `themes/sea.tvtheme` в редакторе, поменяйте цвет меню и
   сохраните под новым именем — тема появится в меню примера.
3. Добавьте в свою программу из урока 9 меню «Тема» с `choose_theme`.

## Важно запомнить

* Тема — палитра приложения в файле `.tvtheme`; делается в
  `cargo run -p tvtheme`.
* `app.load_theme(путь)` — подключить; `TVISION_THEME=путь` — без кода.
* `find_themes(каталог)` — все темы, `choose_theme(app, &темы)` — выбор с
  предпросмотром, `app.set_theme(&тема)` — сменить.
