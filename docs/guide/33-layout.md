## `Layout` — раскладка

**Что это.** Описание того, как расставить элементы: строка, столбец,
сетка или форма, с промежутками, полями и распорками. Создаётся
построителями [`HBox::new()`](#hbox-и-vbox--строка-и-столбец),
`VBox::new()`, [`Grid::new()`](#grid--сетка),
[`Form::new()`](#form--форма); методы вызываются цепочкой.

```rust
use tvision::layout::*;
use tvision::*;

fn settings() -> Dialog {
    let mut d = Dialog::centered(40, 10, "Параметры");
    let path = d.add(InputLine::new(Rect::default(), 60));
    let browse = d.add(Button::new(Rect::default(), "~О~бзор...", cm::OK, bf::NORMAL));
    let lp = d.add(Label::new(Rect::default(), "~П~апка:", Some(path)));
    let opts = d.add(Cluster::check_boxes(Rect::default(), &["~С~крытые файлы", "~П~одкаталоги"]));
    let ok = d.add(Button::new(Rect::default(), "O~K~", cm::OK, bf::DEFAULT));
    d.set_layout(
        VBox::new()
            .margin(1)
            .add(HBox::new().add(lp).add(path).add(browse)) // подпись, поле, кнопка — в строку
            .space(1)
            .add(opts)
            .stretch(1)
            .add(HBox::new().stretch(1).add(ok)),
    );
    d.adjust_size();
    d
}

fn check() {
    let d = settings();
    let ok = d.win.group.children.iter().rev().find(|c| c.as_any().is::<Button>()).unwrap();
    assert_eq!(ok.vs().bounds().b.x, d.win.group.vs.size.x - 2); // у правого края (рамка + поле)
}
```

| Метод | Что делает |
|-------|-----------|
| `add(элемент)` | добавить: `ViewId`, вложенную раскладку, [`Spacer`](#spacer--распорка) или [`item(…)`](#item-и-item--уточнения-элемента) |
| `stretch(n)` | пружина с коэффициентом `n` (как `addStretch`) |
| `space(n)` | пустое место ровно `n` клеток (как `addSpacing`) |
| `spacing(n)` | промежуток между элементами (у сетки и формы — по обеим осям) |
| `hspacing(n)`, `vspacing(n)` | промежуток между столбцами / строками |
| `margins(слева, сверху, справа, снизу)`, `margin(n)` | поля вокруг |
| `size_hint(&группа)`, `min_size(&группа)` | желаемый и минимальный размер раскладки |
| `apply(&mut группа, прямоугольник)` | расставить один раз (обычно не нужно: это делает окно) |
| `geometry(&группа, прямоугольник)` | где окажется каждый элемент — без изменений (для тестов) |

Методы сетки и формы — ниже.

## `HBox` и `VBox` — строка и столбец

**Что это.** `HBox::new()` — элементы слева направо (`QHBoxLayout`),
`VBox::new()` — сверху вниз (`QVBoxLayout`). Промежуток по умолчанию: в
строке 1 клетка, в столбце 0.

```rust
use tvision::layout::*;
use tvision::*;

fn toolbar() {
    let mut g = Group::new(Rect::new(0, 0, 50, 2));
    let a = g.insert(Box::new(Button::new(Rect::default(), "~Н~овый", cm::OK, bf::NORMAL)));
    let b = g.insert(Box::new(Button::new(Rect::default(), "~О~ткрыть", cm::OK, bf::NORMAL)));
    let c = g.insert(Box::new(Button::new(Rect::default(), "~В~ыход", cm::QUIT, bf::NORMAL)));
    // Две кнопки слева, одна справа.
    g.set_layout(HBox::new().add(a).add(b).stretch(1).add(c));
    assert_eq!(g.view(c).unwrap().vs().bounds(), Rect::new(40, 0, 50, 2));
}
```

**Типичные приёмы:**

| Чего хотим | Как |
|------------|-----|
| кнопки справа | `HBox::new().stretch(1).add(ok).add(cancel)` |
| кнопки по центру | `HBox::new().stretch(1).add(ok).add(cancel).stretch(1)` |
| кнопки внизу окна | в `VBox` перед рядом кнопок — `.stretch(1)` |
| подпись, поле, кнопка «…» | `HBox::new().add(label).add(input).add(button)` — строка ввода заберёт лишнее |
| два списка 1:2 | `HBox::new().add(item(a).stretch(1)).add(item(b).stretch(2))` |

## `Grid` — сетка

**Что это.** Элементы по строкам и столбцам (`QGridLayout`); элемент
может занимать несколько клеток. Ширина столбца — по самому широкому
элементу в нём, высота строки — по самому высокому. Промежутки: 1 между
столбцами, 0 между строками.

```rust
use tvision::layout::*;
use tvision::*;

fn grid() {
    let mut g = Group::new(Rect::new(0, 0, 41, 6));
    let b: Vec<ViewId> = (0..3).map(|_| g.insert(Box::new(Button::new(Rect::default(), "X", cm::OK, bf::NORMAL)))).collect();
    let wide = g.insert(Box::new(Button::new(Rect::default(), "Широкая", cm::OK, bf::NORMAL)));
    g.set_layout(
        Grid::new()
            .cell(0, 0, item(b[0]).expand())
            .cell(0, 1, item(b[1]).expand())
            .cell(0, 2, item(b[2]).expand())
            .span(1, 0, 1, 3, item(wide).expand()) // на три столбца
            .col_stretch(0, 1)
            .col_stretch(1, 1)
            .col_stretch(2, 1),
    );
    assert_eq!(g.view(b[1]).unwrap().vs().bounds().a.x, 14); // (41 - 2) / 3 = 13 + промежуток
    assert_eq!(g.view(wide).unwrap().vs().bounds().b.x, 41);
}
```

| Метод | Что делает |
|-------|-----------|
| `cell(строка, столбец, элемент)` | элемент в одну клетку |
| `span(строка, столбец, строк, столбцов, элемент)` | на несколько клеток |
| `col_stretch(столбец, n)`, `row_stretch(строка, n)` | как делить лишнее место |
| `add(элемент)` | в новую строку, в столбец 0 |

**Что важно знать.** Элемент в клетке растягивается на всю клетку, только
если его политика позволяет расти; иначе он желаемого размера в левом
верхнем углу клетки (поменять — [`align_h`/`align_v`](#item-и-item--уточнения-элемента)).
Пустые строки и столбцы места и промежутков не занимают.

## `Form` — форма

**Что это.** Строки «подпись — поле» (`QFormLayout`): столбец подписей
шириной по самой длинной, поля — на всю оставшуюся ширину. Промежутки:
1 между подписью и полем и 1 между строками — как в диалогах Turbo
Vision.

| Метод | Что делает |
|-------|-----------|
| `row(подпись, поле)` | строка формы; поле — любой элемент или раскладка (например, `HBox` из строки ввода и кнопки истории) |
| `row_wide(элемент)` | элемент на обе колонки (флажок, пояснение) |

Форма — это сетка из двух столбцов, поэтому для неё работают и методы
сетки.

## `Item` и `item` — уточнения элемента

**Что это.** Элемент раскладки с уточнениями. Обычно создаётся неявно
(`.add(id)`), а явно — функцией `item(…)`, чтобы что-то поменять:

```rust,ignore
.add(item(table).stretch(2).min(20, 5))
.add(item(title).align_h(Alignment::Center))
.add(item(code_input).fixed_width(8))
```

| Метод | Что делает |
|-------|-----------|
| `stretch(n)` | коэффициент растяжения |
| `expand()` | тянуться во все стороны |
| `policy(по_ширине, по_высоте)` | своя политика вместо политики элемента |
| `hint(w, h)` | свой желаемый размер |
| `fixed(w, h)`, `fixed_width(w)`, `fixed_height(h)` | ровно такой размер |
| `min(w, h)`, `max(w, h)`, `min_width`, `max_width`, `min_height`, `max_height` | пределы |
| `align_h(a)`, `align_v(a)`, `center()` | выравнивание вместо растягивания ([`Alignment`](#alignment)) |

## `Spacer` — распорка

Пустое место (`QSpacerItem`). В строках и столбцах удобнее `.stretch(n)`
и `.space(n)`; `Spacer` — для сетки и особых случаев.

| Создать | Что |
|---------|-----|
| `Spacer::horizontal()` | пружина по ширине |
| `Spacer::vertical()` | пружина по высоте |
| `Spacer::fixed(w, h)` | ровно `w × h` |
| `Spacer::new(w, h, политика_ш, политика_в)` | любая |

Рядом с распорками промежуток раскладки не ставится.

## `Policy` и `SizePolicy`

`Policy` — как элемент относится к месту по одной оси (`QSizePolicy::Policy`):

| Значение | Растёт | Сжимается |
|----------|--------|-----------|
| `Fixed` | нет | нет |
| `Minimum` | да | нет (не меньше желаемого) |
| `Maximum` | нет | да |
| `Preferred` | да | до минимума (у элементов — до желаемого) |
| `Expanding` | да, **в первую очередь** | до минимума (у элементов — 5 по ширине, 3 по высоте) |
| `Ignored` | да, в первую очередь | желаемый размер не учитывается |

`SizePolicy { h, v }` — пара политик. Готовые: `SizePolicy::FIXED`,
`PREFERRED` (по умолчанию: ширина `Preferred`, высота `Fixed`),
`EXPANDING_H` (строка ввода), `EXPANDING` (таблица, список).

## `Alignment`

Как поставить элемент, если ему дали больше места, чем он хочет:
`Fill` (по умолчанию: растянуть, если политика позволяет), `Start`
(влево / вверх), `Center`, `End` (вправо / вниз). С `Start`, `Center` и
`End` элемент всегда желаемого размера.

## `Margins`

Поля раскладки: `left`, `top`, `right`, `bottom`. Задаются методами
`margins(…)` и `margin(n)`.

## Раскладка в окне и группе

| Метод | Что делает |
|-------|-----------|
| `Window::set_layout(раскладка)`, `Dialog::set_layout(…)` | расставлять элементы внутри рамки; пересчёт — при каждом изменении размера окна |
| `Window::adjust_size()`, `Dialog::adjust_size()` | размер окна по желаемому размеру раскладки (левый верхний угол на месте; диалог с `of::CENTERED` встанет по центру при открытии) |
| `Group::set_layout(раскладка)` | то же для любой группы, без отступа под рамку |
| `Group::apply_layout()` | пересчитать сейчас — после скрытия элемента или смены надписи |
| поле `Group::layout` | сама раскладка (`Option<Box<Layout>>`) |

**Что важно знать.**

* Окно нельзя сделать меньше минимума раскладки (и меньше 16 × 6).
* Элементы, которых нет в раскладке, двигаются по своему `grow_mode`.
* Скрытые элементы (`sf::VISIBLE` снят) места не занимают.

## Свой элемент в раскладке

Раскладка спрашивает у представления два метода трейта `View`:

```rust,ignore
impl View for Gauge {
    // …
    fn size_hint(&self) -> Option<Point> {
        Some(Point::new(self.label.chars().count() as i32 + 12, 1))   // желаемый размер
    }
    fn size_policy(&self) -> layout::SizePolicy {
        layout::SizePolicy::EXPANDING_H                                // тянуться по ширине
    }
}
```

`size_hint` по умолчанию — `None`: тогда желаемым считается размер, с
которым элемент был создан. `size_policy` по умолчанию —
`SizePolicy::PREFERRED`.

## Как считаются размеры

1. **Измерение.** Для каждого элемента — желаемый размер, минимум,
   максимум и политика по обеим осям; у вложенной раскладки — сумма по
   длине и наибольшее поперёк, плюс промежутки и поля.
2. **Раздача места вдоль строки:**
   * есть коэффициенты растяжения — элементы без них получают желаемый
     размер, остальное делится по коэффициентам (не меньше минимумов, не
     больше максимумов);
   * иначе лишнее получают `Expanding`, а если таких нет — все, кто
     может расти; поровну, до своего максимума;
   * места не хватает — сжимаются сжимаемые, пропорционально запасу до
     минимума.
3. **Поперёк строки** элемент занимает всё место, если может расти и
   выравнивание `Fill`, иначе — желаемый размер с выравниванием.

Это тот же порядок, что у раскладок Qt, поэтому привычные приёмы
(пружины, коэффициенты, `Expanding`) работают так же.
