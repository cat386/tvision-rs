# Урок 2. Меню и команды

Теперь у программы появятся меню наверху и свой код, который отвечает
на выбор пунктов. По F2 программа будет здороваться.

## Как устроены команды

Когда пользователь выбирает пункт меню, нажимает кнопку или клавишу из
строки состояния, программа получает **команду** — просто число. Одни
команды обрабатывает сама библиотека (`cm::QUIT` — выход, `cm::CLOSE` —
закрыть окно), другие придумываете вы.

Свои команды не обработает никто, кроме вашего кода. Этот код живёт в
**обработчике приложения** — структуре, для которой вы реализуете трейт
`AppHandler`. Программа передаёт ему все команды, которые не забрали
окна и кнопки.

```text
  пункт меню «Привет» ──► команда CM_HELLO ──► окна? нет ──► ваш AppHandler
```

## Программа

Файл `examples/learn_02_menu.rs`:

```rust,ignore
//! Урок 2. Меню, строка состояния и свои команды.
//!
//! Запуск: `cargo run --example learn_02_menu`. F10 — меню, F2 — приветствие,
//! Alt+X — выход.

use tvision::*;

// Свои команды. Это просто числа; главное — не пересечься со стандартными
// (`cm::QUIT`, `cm::OK`…), которые заняли номера меньше 100.
const CM_HELLO: u16 = 100;
const CM_ABOUT: u16 = 101;

/// Наше приложение. Здесь живут данные программы — пока только счётчик.
struct App {
    greetings: u32,
}

// `AppHandler` — «мозг» программы: сюда приходят команды из меню и строки
// состояния, которые не обработал никто другой.
impl AppHandler for App {
    fn handle_event(&mut self, app: &mut Program, ev: &mut Event) {
        match ev.command() {
            Some(CM_HELLO) => {
                self.greetings += 1;
                let text = format!("\x03Привет! Это приветствие номер {}.", self.greetings);
                message_box(app, &text, mf::INFORMATION | mf::OK_BUTTON);
            }
            Some(CM_ABOUT) => {
                message_box(app, "\x03Урок 2\n\x03Меню и команды", mf::INFORMATION | mf::OK_BUTTON);
            }
            // Чужие события не трогаем — просто выходим.
            _ => return,
        }
        // Команда обработана: помечаем событие, чтобы оно не пошло дальше.
        ev.clear();
    }
}

/// Строка меню: два выпадающих меню.
fn menu() -> Menu {
    Menu::new()
        .submenu(
            "~Ф~айл", // тильды выделяют горячую букву: Alt+Ф откроет это меню
            Menu::new()
                .item_key("~П~ривет", CM_HELLO, kb::F2, "F2") // пункт, клавиша F2, подпись «F2»
                .separator() // черта-разделитель
                .item_key("~В~ыход", cm::QUIT, kb::ALT_X, "Alt-X"),
        )
        .submenu("~С~правка", Menu::new().item("~О~ программе", CM_ABOUT))
}

/// Строка состояния.
fn status() -> Vec<StatusDef> {
    vec![StatusDef::all(vec![
        StatusItem::new("~F2~ Привет", kb::F2, CM_HELLO),
        StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT),
        StatusItem::new("", kb::F10, cm::MENU), // без надписи: F10 открывает меню
    ])]
}

fn main() -> std::io::Result<()> {
    // Кнопки окон сообщений («Да», «Отмена»…) — по-русски.
    locale::set_language(locale::Language::Ru);
    let mut app = Program::with_terminal(Some(menu()), Some(status()))?;
    app.run(&mut App { greetings: 0 });
    Ok(())
}
```

Запуск: `cargo run --example learn_02_menu`. Нажмите F10 или щёлкните по
слову «Файл» — откроется меню. F2 — окно с приветствием, Enter или Esc —
закрыть его.

## Разбор

### Свои команды

```rust,ignore
const CM_HELLO: u16 = 100;
const CM_ABOUT: u16 = 101;
```

Команда — число типа `u16`. Стандартные команды библиотеки (`cm::QUIT`,
`cm::OK` и другие) заняли номера меньше 100, поэтому свои начинаем со
100. Имена `CM_…` — традиция из Turbo Vision («command»).

### Обработчик приложения

```rust,ignore
struct App {
    greetings: u32,
}

impl AppHandler for App {
    fn handle_event(&mut self, app: &mut Program, ev: &mut Event) {
        match ev.command() {
            Some(CM_HELLO) => { … }
            Some(CM_ABOUT) => { … }
            _ => return,
        }
        ev.clear();
    }
}
```

* `App` — наша структура. В ней можно хранить любые данные программы;
  здесь — сколько раз мы поздоровались.
* `handle_event` вызывается для каждого необработанного события. Два
  параметра: `app` — сама программа (через неё показывают окна и
  диалоги), `ev` — событие.
* `ev.command()` возвращает номер команды, если событие — команда, или
  `None`, если это что-то другое.
* **`ev.clear()`** — «я это обработал». Событие становится пустым и
  дальше не идёт. Если забыть `clear`, ничего страшного не случится, но
  привыкайте ставить его всегда — в окнах и диалогах это важно.
* `_ => return` — чужие события пропускаем, не трогая.

### Окно сообщения

```rust,ignore
message_box(app, &text, mf::INFORMATION | mf::OK_BUTTON);
```

`message_box` показывает небольшое окно с текстом и кнопками и ждёт,
пока его закроют. Флаги `mf::…` выбирают заголовок (`INFORMATION` —
«Информация», `WARNING`, `ERROR`, `CONFIRMATION`) и кнопки (`OK_BUTTON`,
`YES_BUTTON`, `NO_BUTTON`, `CANCEL_BUTTON`). Флаги складываются знаком
`|`. Функция возвращает команду нажатой кнопки — например, `cm::YES`.

Символ `\x03` в начале строки — «расположить текст по центру». `\n` —
перенос строки.

### Меню

```rust,ignore
Menu::new()
    .submenu("~Ф~айл", Menu::new()
        .item_key("~П~ривет", CM_HELLO, kb::F2, "F2")
        .separator()
        .item_key("~В~ыход", cm::QUIT, kb::ALT_X, "Alt-X"))
    .submenu("~С~правка", Menu::new().item("~О~ программе", CM_ABOUT))
```

Меню собирается **цепочкой вызовов**: каждый метод добавляет что-то и
возвращает меню дальше.

* `submenu(название, меню)` — выпадающее меню в строке меню. Тильды
  выделяют **горячую букву**: Alt+Ф откроет «Файл». В открытом меню
  пункт выбирается просто буквой.
* `item(название, команда)` — пункт меню.
* `item_key(название, команда, клавиша, подпись)` — пункт с **клавишей
  быстрого вызова**: F2 сработает, даже когда меню закрыто. Подпись `"F2"`
  только рисуется справа от названия.
* `separator()` — черта между пунктами.

### Строка состояния

```rust,ignore
StatusItem::new("~F2~ Привет", kb::F2, CM_HELLO),
StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT),
StatusItem::new("", kb::F10, cm::MENU),
```

Пункт с пустой надписью **не виден**, но его клавиша работает. Так F10
открывает меню (`cm::MENU`), не занимая места внизу.

### Язык

```rust,ignore
locale::set_language(locale::Language::Ru);
```

Надписи, которые рисует сама библиотека (кнопки «OK», «Отмена», заголовки
окон сообщений), по умолчанию английские. Эта строка делает их
русскими. Надписи вашей программы вы пишете сами на любом языке.

### Запуск с обработчиком

```rust,ignore
app.run(&mut App { greetings: 0 });
```

Вместо `NoHandler` передаём свой обработчик. `&mut` — потому что
обработчик меняет свои данные (счётчик).

## Попробуйте

1. Добавьте в «Справку» пункт «Версия» с командой `CM_VERSION = 102`,
   который показывает номер версии.
2. Сделайте пункт «Выход» с вопросом: `message_box(…, mf::CONFIRMATION |
   mf::YES_BUTTON | mf::NO_BUTTON)` и, если ответ `cm::YES`, —
   `app.quit()`. (Пункт должен посылать свою команду, а не `cm::QUIT`.)
3. Нажмите F2 несколько раз подряд — счётчик растёт.

## Важно запомнить

* Свои команды — константы `u16` от 100.
* Команды приходят в `AppHandler::handle_event`; обработали — `ev.clear()`.
* Не назначайте пункту строки состояния Enter, Esc, Tab или буквы:
  строка состояния видит клавиши раньше всех, и они перестанут работать
  в диалогах.
