Программа большая (около 500 строк вместе с комментариями и тестами),
поэтому здесь — не весь код, а **карта**: из каких частей она состоит и
что в каждой нового. Откройте рядом файл `examples/guide_contacts.rs` и
запустите:

```text
cargo run --example guide_contacts
```

Попробуйте: Ins — добавить, Enter или F4 — изменить, Del — удалить,
F2 — сохранить (в первый раз спросит имя файла), Alt+X — выйти (спросит,
сохранить ли изменения).

## Таблица

В уроке 8 данные показывал список `ListBox`. Для нескольких столбцов
есть **таблица** `Table`:

```rust,ignore
let model = VecTableModel::new(&["Имя", "Телефон", "Почта", "Группа", "★"], Vec::new());
let cols = vec![
    TableColumn::new(22),
    TableColumn::new(18),
    TableColumn::new(22),
    TableColumn::new(8),
    TableColumn::new(3).align(Align::Center),
];
let mut table = Table::new(win.interior(), Box::new(model), Some(v), Some(h))
    .with_columns(cols)
    .selection(SelectionMode::Row)
    .striped(true)
    .sortable(false);
table.vs.grow_mode = gf::GROW_HI_X | gf::GROW_HI_Y;
```

* Таблица берёт ячейки из **модели**. `VecTableModel` — самая простая
  модель: заголовки и строки как `Vec<Vec<String>>`.
* `TableColumn::new(ширина)` — описание столбца; `.align(…)` —
  выравнивание.
* Настройки цепочкой: `.selection(SelectionMode::Row)` — курсор на всю
  строку, `.striped(true)` — строки через одну чуть другого цвета,
  `.sortable(false)` — не сортировать щелчком по заголовку (мы сортируем
  сами, командой, — так номер строки таблицы всегда равен номеру
  контакта в `contacts`).
* `v`, `h` — полосы прокрутки на рамке: `win.standard_scroll_bar(true)` и
  `(false)`.
* `grow_mode` — чтобы таблица растягивалась вместе с окном
  ([урок 4](04-coordinates.md#растягивание)).

Как в уроке 8, есть метод `reload`, который перекладывает `contacts` в
таблицу; его вызывают после каждого изменения. Строка под курсором —
`table.cursor().0`.

## Enter в таблице

Таблица не «съедает» Enter: если она его не обработала, Enter
возвращается к окну. Окно этим пользуется — превращает Enter (и двойной
щелчок) в команду «Изменить»:

```rust,ignore
fn handle_event(&mut self, ev: &mut Event, ctx: &mut Ctx) {
    let double = matches!(ev, Event::MouseDown(m) if m.double);
    self.win.handle_window_event(ev, ctx);
    if matches!(ev, Event::KeyDown(k) if k.key == Key::Enter && k.mods == Mods::NONE) || double {
        ctx.post_command(CM_EDIT, Info::None);
        ev.clear();
    }
}
```

`ctx.post_command(команда, Info::None)` ставит команду в очередь — она
придёт в `AppHandler`, как будто её выбрали в меню. Так окно и
обработчик приложения «разговаривают».

## Проверка ввода в диалоге

```rust,ignore
let name = InputLine::new(Rect::new(13, 2, 49, 3), 60)
    .with_validator(FnValidator { f: |s: &str| !s.trim().is_empty(), message: "Имя не может быть пустым.".into() });
```

`FnValidator` проверяет поле **вашей функцией**: `f` получает текст и
возвращает `true`, если всё хорошо; `message` — что сказать, если нет.
Проверка срабатывает при нажатии OK. Телефону поставлен
`FilterValidator` — буквы в нём просто не набираются.

## Запрет недоступных команд

Если контактов нет, «Изменить» и «Удалить» не имеют смысла. Их можно
**запретить**: пункты меню и строки состояния станут серыми, а клавиши
перестанут срабатывать.

```rust,ignore
fn idle(&mut self, app: &mut Program) {
    let (has_window, has_rows) = match Self::window(app) {
        Some(w) => (true, !w.contacts.is_empty()),
        None => (false, false),
    };
    for (cmd, on) in [(CM_ADD, has_window), (CM_EDIT, has_rows), (CM_DELETE, has_rows) /* … */] {
        if on { app.enable_command(cmd); } else { app.disable_command(cmd); }
    }
}
```

`idle` — второй метод `AppHandler`: программа вызывает его, когда
событий нет. Удобное место, чтобы привести команды в порядок.

> Запрещать можно только команды с номерами до 255 — поэтому свои
> команды удобно нумеровать от 100 до 255.

## Файлы

Чтение и запись — обычный Rust (`std::fs`). От интерфейса нужен только
выбор файла — для этого есть готовый диалог:

```rust,ignore
let d = FileDialog::new("*.tsv", "Открыть", "~И~мя", fd::OPEN_BUTTON, 100);
let (cmd, d) = app.exec_dialog(d);
if cmd == cm::CANCEL {
    return;
}
let path = d.file_name();
```

`FileDialog::new(шаблон, заголовок, подпись поля, кнопки, номер истории)`:
показывает файлы по шаблону, даёт ходить по каталогам и запоминает
введённые имена (номер истории — любое число, у каждого диалога свой).
Для «Сохранить как» — кнопка `fd::OK_BUTTON`.

## Вопрос при выходе

```rust,ignore
match message_box(app, "\x03Сохранить изменения?", mf::CONFIRMATION | mf::YES_NO_CANCEL) {
    cm::YES => self.save(app, false),
    cm::NO => true,
    _ => false,
}
```

Три кнопки — «Да», «Нет», «Отмена». Выход сделан своей командой
`CM_EXIT` (а не `cm::QUIT`), чтобы успеть спросить: только если ответ
не «Отмена», вызывается `app.quit()`.
