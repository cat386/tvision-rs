## `Menu` — меню

**Что это.** Список пунктов меню. Его передают программе, и она делает
из него **строку меню** наверху экрана; вложенные меню становятся
выпадающими.

**Аналог:** `TMenu` и функции `newSubMenu`, `newItem`, `newLine`.

```rust
use tvision::*;

const CM_ABOUT: u16 = 120;

fn menu() -> Menu {
    Menu::new()
        .submenu("~С~правка", Menu::new().item("~О~ программе...", CM_ABOUT))
        .submenu(
            "~Ф~айл",
            Menu::new()
                .item_key("~О~ткрыть...", cm::OPEN, kb::F3, "F3")
                .submenu("~Н~едавние", Menu::new().item("a.txt", 200).item("b.txt", 201)) // вложенное
                .separator()
                .item_key("~В~ыход", cm::QUIT, kb::ALT_X, "Alt-X"),
        )
}

fn check() {
    let m = menu();
    assert_eq!(m.items.len(), 2);
    assert_eq!(m.find_hot_key(&kb::F3), Some(cm::OPEN)); // какая команда у F3
}
```

| Метод | Что добавляет |
|-------|---------------|
| `Menu::new()` | пустое меню |
| `item(название, команда)` | пункт |
| `item_key(название, команда, клавиша, "подпись")` | пункт с клавишей быстрого вызова (работает и при закрытом меню); подпись рисуется справа |
| `submenu(название, меню)` | вложенное меню |
| `submenu_key(название, клавиша, меню)` | вложенное меню, которое открывается ещё и клавишей |
| `separator()` | черту |
| `help(номер)` | номер темы справки для **последнего** добавленного пункта |

**Реже:** `items` (пункты списком), `find_hot_key(&клавиша)`,
`find_item(буква)`, `box_size()`, `bar_positions()`.

**Как работает меню у пользователя.** F10 (команда `cm::MENU`) или щелчок
открывает строку меню; Alt+буква — сразу нужное меню (в любой
раскладке: Alt+Ф и Alt+A одинаковы); стрелки, Enter и Esc — внутри;
пункт выбирается и горячей буквой. Пункты с запрещённой командой серые.

> Клавиши пунктов меню ловятся **раньше** полей ввода. Не назначайте
> пунктам буквы, Enter или Ctrl+стрелки — их перестанут получать поля.

## `MenuItem` — пункт меню

**Что это.** Один пункт: `Command` (команда), `SubMenu` (вложенное
меню) или `Separator` (черта). Обычно создаётся методами `Menu`, а не
вручную. Методы: `name()`, `is_separator()`, `enabled(&команды)`,
`help_ctx()`.

## `MenuBar` — строка меню

**Что это.** Верхняя строка экрана с названиями меню. Программа создаёт
её сама; её id — `app.menu_bar_id`. Поле `menu` можно заменить, чтобы
поменять меню на ходу:

```rust
use std::rc::Rc;
use tvision::*;

fn replace_menu(app: &mut Program, m: Menu) {
    if let Some(id) = app.menu_bar_id {
        if let Some(bar) = app.find_mut::<MenuBar>(id) {
            bar.menu = Rc::new(m);
        }
    }
}
```

**Реже:** `MenuBar::new(границы, меню)`, `active`, `item_at(x)`.

## Контекстное меню

**Что это.** Меню, которое всплывает там, где щёлкнули правой кнопкой.
Открывается так: `ctx.popup_menu(меню, точка)` из представления или
`app.ctx.popup_menu(меню, точка)` из обработчика приложения. Точка —
**экранная**.

```rust
use std::rc::Rc;
use tvision::*;

const CM_COPY_PATH: u16 = 131;

/// Правая кнопка мыши по свободному месту рабочего стола
/// (такие щелчки доходят до обработчика приложения).
fn context_menu(app: &mut Program, ev: &mut Event) {
    if let Event::MouseDown(m) = ev {
        if m.buttons & event::MB_RIGHT != 0 {
            let menu = Rc::new(Menu::new().item("~К~опировать путь", CM_COPY_PATH).separator().item("~М~озаика", cm::TILE));
            app.ctx.popup_menu(menu, m.pos); // здесь m.pos уже экранная
            ev.clear();
        }
    }
}
```

Выбранный пункт посылает команду обычным путём.

## `MenuSession` и `MenuOutcome`

Служебное: пока меню открыто, им управляет «сеанс меню» `MenuSession`,
который сообщает итог — `MenuOutcome::Continue` (меню ещё открыто),
`Closed` (закрыли без выбора) или `Command(cmd)`. Самим вызывать не
нужно. `menu::draw_menu_box` рисует выпадающее окно меню.

## `StatusLine` — строка состояния

**Что это.** Нижняя строка экрана с подсказками клавиш: пункт «F2
Сохранить» и показывает подсказку, и сам срабатывает по F2.

**Аналог:** `TStatusLine`.

Пунктов может быть несколько **наборов** — для разных мест программы.
Какой показывать, решает **номер темы справки** (`help_ctx`) элемента в
фокусе: например, в редакторе — одни клавиши, в списке — другие.

```rust
use tvision::*;

const HC_EDITOR: u16 = 100;
const CM_BUILD: u16 = 140;

fn status() -> Vec<StatusDef> {
    vec![
        // Когда в фокусе элемент с vs.help_ctx == HC_EDITOR:
        StatusDef::range(HC_EDITOR, HC_EDITOR, vec![
            StatusItem::new("~F2~ Сохранить", kb::F2, cm::SAVE),
            StatusItem::new("~F9~ Собрать", kb::f(9), CM_BUILD),
            StatusItem::new("", kb::F10, cm::MENU),
        ]),
        // Во всех остальных случаях (подходит первый набор по порядку):
        StatusDef::all(vec![
            StatusItem::new("~Alt-X~ Выход", kb::ALT_X, cm::QUIT),
            StatusItem::new("", kb::F10, cm::MENU), // невидимые — только клавиши
            StatusItem::new("", kb::ALT_F3, cm::CLOSE),
            StatusItem::new("", kb::F5, cm::ZOOM),
            StatusItem::new("", kb::F6, cm::NEXT),
        ]),
    ]
}

/// Подсказка справа от пунктов.
fn add_hint(app: &mut Program) {
    if let Some(sl) = app.status_line_mut() {
        sl.hint = Some(Box::new(|ctx| if ctx == HC_EDITOR { "Правка текста".into() } else { String::new() }));
    }
}
```

**Что важно знать.**

* Пункт с **пустой надписью** не виден, но его клавиша работает. Удобно
  для F10, Alt+F3, F5, F6.
* Строка состояния видит клавиши **раньше всех** — даже в открытом
  диалоге. Поэтому F1 из строки состояния открывает справку где угодно.
  Но поэтому же **нельзя** вешать пункты на Enter, Esc, Tab и буквы —
  они перестанут работать в полях и диалогах.
* Пункт с запрещённой командой рисуется серым и не срабатывает.

**Поля:** `defs` (наборы — можно заменить), `hint` (подсказка),
`help_ctx`. **Реже:** `StatusLine::new(границы, наборы)`, `items()`.

## `StatusDef` — набор пунктов

`StatusDef::all(пункты)` — для всех мест программы;
`StatusDef::range(от, до, пункты)` — когда номер темы справки в
диапазоне. Поля `min`, `max`, `items`.

## `StatusItem` — пункт строки состояния

`StatusItem::new("~F2~ Сохранить", kb::F2, cm::SAVE)`: надпись (часть
в тильдах выделяется цветом), клавиша, команда. Поля `text`, `key`,
`command`. Пункт с командой 0 — просто надпись.

## `HintFn` — подсказка

Функция `номер темы → текст`, которая рисует подсказку в правой части
строки состояния (`status_line.hint`, пример выше).
