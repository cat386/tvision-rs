# 13. Язык интерфейса и раскладки клавиатуры

## Надписи библиотеки: модуль `locale`

Часть надписей рисует сама библиотека: кнопки и заголовки окон
сообщений, диалоги файлов и смены каталога, сообщения валидаторов,
окно справки, поиск в редакторе, «<empty>» в пустом списке. По умолчанию
они английские, как в оригинальном Turbo Vision. Русский включается
одной строкой в начале `main`:

```rust
use tvision::*;

fn main() -> std::io::Result<()> {
    locale::set_language(locale::Language::Ru);
    let mut app = Program::with_terminal(None, None)?;
    app.run(&mut program::NoHandler);
    Ok(())
}
```

| Функция | Что делает |
|---------|-----------|
| `locale::set_language(Language::En / Ru)` | выбрать язык (для текущего потока) |
| `locale::language()` | текущий язык |
| `locale::tr(s)` | перевод английской надписи библиотеки на текущий язык (если перевода нет — сама строка) |

Что переводится:

| По-английски | По-русски |
|--------------|-----------|
| `~Y~es`, `~N~o`, `O~K~`, `Cancel` | `~Д~а`, `~Н~ет`, `O~K~`, `Отмена` |
| Warning, Error, Information, Confirm | Предупреждение, Ошибка, Информация, Подтверждение |
| `~F~iles`, `~O~pen`, `~R~eplace`, `~C~lear`, `~H~elp`, `~N~ame` | `~Ф~айлы`, `~О~ткрыть`, `~З~аменить`, `О~ч~истить`, `~С~правка`, `~И~мя` |
| Change Directory, `Directory ~n~ame`, `Directory ~t~ree`, `~C~hdir`, `~R~evert` | Смена каталога, `~И~мя каталога`, `~Д~ерево каталогов`, `~П~ерейти`, `~В~ернуть` |
| Invalid drive or directory, Invalid file name, Invalid directory: | Неверный диск или каталог, Неверное имя файла, Неверный каталог: |
| Help, No help available in this context. | Справка, Справка для этого места отсутствует. |
| сообщения валидаторов и `InputLong` | «Ввод не соответствует шаблону:», «Недопустимый символ», «Значение вне диапазона … до …», «Такого значения нет в списке допустимых» |
| Colors, `~G~roup`, `~I~tem`, `~F~oreground`, `~B~ackground` | Цвета, `~Г~руппа`, `~Э~лемент`, `~Т~екст`, `~Ф~он` |
| `<empty>` | `<пусто>` |
| Untitled, Find, Replace, `~T~ext to find`, `~N~ew text`, флажки поиска, вопросы редактора | Без имени, Поиск, Замена, `~И~скать`, `~Н~овый текст`… |

При русском языке даты в панели сведений диалога файлов пишутся как
`23.10.2026 21:53`.

Английские константы (`MsgBoxText::OK`, `FileDialogText::OPEN`,
`ColorDialogText::GROUP`, `listbox::EMPTY_TEXT`, `editor::UNTITLED`…)
остались прежними — это «ключи» перевода.

Надписи **вашей** программы (меню, диалоги) вы пишете сами на нужном
языке; `tr` для них не нужен.

## Горячие буквы в любой раскладке

На Windows Alt+буква и Ctrl+буква приходят **латинской** буквой той же
клавиши — даже в русской раскладке: Alt+Ф — это `alt('a')`. Иначе Alt+X
перестал бы работать при включённой русской раскладке.

Поэтому библиотека сравнивает горячие буквы **без учёта раскладки**
(`text::same_hotkey`, пары клавиш QWERTY ↔ ЙЦУКЕН):

* меню: Alt+A и Alt+Ф открывают «~Ф~айл»; в открытом меню буква тоже ищется
  в обеих раскладках;
* метки, кнопки, флажки и переключатели: Alt+буква срабатывает и на
  латинскую, и на русскую букву той же клавиши.

Буква **без** Alt (в открытом меню или когда элемент в фокусе её не взял)
сравнивается как есть: в русской раскладке пользователь и так набирает
русскую букву.

Следствие для раскладки диалогов: горячие буквы `~К~` (клавиша R) и `~R~`
— это одна клавиша. В одном диалоге или меню не используйте пары букв,
стоящих на одной клавише:

```rust
use tvision::*;

fn hotkeys_conflict() {
    assert!(text::same_hotkey('r', 'К')); // одна клавиша
    assert!(text::same_hotkey('a', 'Ф'));
    assert!(!text::same_hotkey('a', 'П'));
}
```

## Своя локализация

Если нужен третий язык или свои формулировки, проще всего:

* для своих надписей — хранить строки в своей таблице;
* для надписей библиотеки — собирать свои варианты диалогов: например,
  вместо `message_box` строить `Dialog` с нужными кнопками
  (`build_message_box` даёт готовый диалог, у которого можно поменять
  `win.title` и надписи кнопок), а у `FileDialog` подпись строки ввода и
  заголовок и так задаёт программа.
