# Qwen Agent — пример на tvision-rs

Терминальный чат с Qwen. Слева — список диалогов, справа — переписка, внизу — многострочный запрос. Модель получает историю выбранного чата и системную инструкцию. Исходники рассчитаны на Windows, Linux и macOS.

## Подключение

Используется официальный OpenAI-совместимый API Alibaba Cloud Model Studio. Нужны отдельный API-ключ, модель и Base URL из консоли Model Studio. Учётная запись веб-чата chat.qwen.ai сама по себе не задаёт параметры API.

1. Создайте API-ключ в Model Studio и скопируйте Base URL для региона и рабочего пространства этого ключа.
2. Перед запуском задайте ключ через переменную окружения.

PowerShell:

    $env:DASHSCOPE_API_KEY = "ваш-api-ключ"
    .\target\release\qwen-agent.exe

Linux/macOS:

    export DASHSCOPE_API_KEY="ваш-api-ключ"
    cargo run --release

3. Нажмите F4. Введите Base URL без /chat/completions, имя модели и системную инструкцию. Пример адреса для рабочего пространства в Сингапуре:

    https://WORKSPACE_ID.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1

Замените WORKSPACE_ID своим идентификатором и используйте регион из своей консоли. Модель по умолчанию — qwen-plus; проверьте её доступность в вашем аккаунте.

4. Введите запрос и нажмите F2. Ключ читается из DASHSCOPE_API_KEY при каждой отправке. В F4 можно изменить имя переменной.

Можно задать QWEN_BASE_URL и QWEN_MODEL перед первым запуском. При последующих запусках используются настройки из файла чатов.

[Официальный API Qwen](https://www.alibabacloud.com/help/en/model-studio/compatibility-of-openai-with-dashscope)
[Получение API-ключа](https://www.alibabacloud.com/help/en/model-studio/get-api-key)

## Управление

| Клавиша | Действие |
| --- | --- |
| F2 | Отправить запрос |
| F4 | Настройки подключения и системная инструкция |
| F5 | Повторить последний запрос без ответа |
| Ctrl+N | Создать чат |
| Tab / Shift+Tab | Перейти между списком чатов, историей, вводом и кнопками |
| Enter в поле запроса | Перевести строку |
| Стрелки в списке чатов | Выбрать диалог |
| Alt+X | Сохранить и выйти |

Ответ ожидается в фоне. Можно переключать чаты и писать черновик. Одновременно выполняется один запрос. После ошибки сообщение остаётся в истории; F5 повторяет его. При закрытии во время запроса сообщение сохраняется, после запуска его можно повторить через F5.

История, черновики и настройки сохраняются в qwen-chats.json в рабочем каталоге. API-ключ программа в этот файл не записывает. Переписка хранится обычным JSON. Другой путь задаётся первым аргументом:

    .\target\release\qwen-agent.exe D:\Chats\qwen.json

Родительский каталог должен существовать. Ошибка чтения существующего файла останавливает запуск, сохраняя его содержимое. Запись выполняется через временный файл с последующей заменой. Для каждого файла данных запускайте одну копию программы.

## Сборка

Нужны Rust и curl в PATH. В Windows используется curl.exe, в Linux/macOS — curl. Пример использует библиотеку из корня этого репозитория и собирается отдельным пакетом Cargo.

    cd examples/qwen-agent
    cargo build --release
    cargo test -p qwen-agent
    cargo clippy -p qwen-agent --no-deps --all-targets -- -D warnings

Из корня репозитория пример запускается командой:

    cargo run --release --manifest-path examples/qwen-agent/Cargo.toml

После сборки исполняемый файл находится в examples/qwen-agent/target/release.

## Устройство

- src/main.rs — интерфейс, чаты, настройки и опрос рабочего потока.
- src/api.rs — POST /chat/completions, JSON, HTTP-ошибки и сетевые тайм-ауты.
- src/fileio.rs — атомарная запись истории, использована реализация из TVStudio.
- ../.. — библиотека интерфейса tvision-rs, лицензия MIT.

Ключ и тело запроса передаются curl через stdin, чтобы ключ отсутствовал в списке аргументов процесса. HTTPS проверяет сертификат штатными средствами curl. Редиректы отключены. Для тестов допускается HTTP на localhost. Тайм-аут подключения — 15 секунд, всего запроса — 120 секунд; ответ ограничен 4 МиБ.

Это пример диалогового помощника с историей. Ответ появляется целиком после завершения запроса. Выполнение команд ОС, изменение файлов проекта и вызовы инструментов в пример не включены. Полная история выбранного чата отправляется модели при каждом запросе; длинная переписка может превысить контекст модели или увеличить стоимость.

## Проверки

Проверяются реальный HTTP-запрос curl к локальному тестовому серверу, формат сообщений, ответ и ошибка API, асинхронный ответ в исходном чате после переключения, сохранение черновика, чтение истории и защита повреждённого файла. Платный запрос Qwen требует вашего ключа и при сборке не выполнялся.
